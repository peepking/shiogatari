# 海賊兵種の比較シミュレーション

実行：`npm run simulate:pirates`（CSVだけが必要なら `node tests/pirateBalance.sim.cjs`）。

6兵種の能力値は本体の `troops.js` から読み込む。シミュレーション自体はゲームの編成・報酬・セーブを変更しない。
兵種の数値を調整すると、次回の実行から比較結果にも反映される。

## 検証内容

- 既存兵種との比較、斧兵対近接・遠隔、突撃兵対斧兵、混成同士の計11組。
- 平原・甲板・森・山岳・浅瀬・海、Lv1・Lv5、1・5・10・20部隊。各部隊10人。
- 528条件で左右を交換し、計1,056戦を実行する。別途、同条件の再実行で再現性を確認する。
- 実際の `battle.js` の部隊生成・移動・射程・標的選択・退避・攻撃を使う。HP倍率と防御軽減式も本体から読む。
- 最大60tick。終了時は本体と同様に、生存側、双方が生存していれば残HP合計で勝敗を判定する。
- 出力は比較側の左右平均勝率、平均残HP率、平均tick。勝率0.5は左右で1勝1敗または引き分けを含む。確率的な勝率推定ではない。

## 条件と限界

均一地形・標準配置・同レベル・同人数で比較する。艤装、船、信仰による能力補正は使用しない。
標的優先は本体と共通。突進抑制は無効、射撃退避は有効。
混成は記載順の兵種を循環させるため、6部隊未満では全兵種を含まない。
左右交換で先行処理と陣営別AIの偏りを確認するが、混合地形・各フォーメーション・配置の違いを網羅するものではない。
兵種間の優劣をテスト成功条件にせず、HP・進行tickの整合性と再現性を検証する。
通常の回帰テストとは別コマンドで実行する。
