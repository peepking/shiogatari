# アート方針

地図・UI・人物・船・施設の現行のデザイン方針と、原画・表示素材の対応をまとめる。

文書を更新する前に、[AGENTS.mdの「設計・アート文書の更新規則」](../AGENTS.md#design-docs) を必ず参照する。制作作業の履歴や生成プロンプトを記録せず、現行の方針・素材仕様・必要な再加工手順を扱う。

## 共通方針

- 中世北欧・西洋の海洋世界を、木・鉄・石・羊毛・帆布・真鍮の素材感で表す。実用的な服装や道具を使い、角付き兜や現代的な装備は使わない。
- 図柄はドット絵とし、輪郭と大きな色のまとまりを優先する。屋根と壁、樹冠と幹、船体とマスト、道具の部品が自然につながる構造にする。
- 濃い紺・青灰の輪郭、生成りの布、暖かい木と真鍮、赤錆色、苔の緑、青灰の鉄を共通の色とする。光は左上から、素材の陰影は少数の明暗面で表す。
- 地点・UIアイコンは約48〜56pxの論理粒度を目安とし、実際の表示サイズで主題を見分けられる形にする。細かな模様、ぼかし、グラデーション、発光に頼らない。
- 信仰の共通モチーフは明るいミントグリーンの海の波。部隊員は3人組、香辛料は赤い唐辛子、食料は小麦の穂、資金は同じ直径の金貨で表す。
- 名称・数量・状態・読み上げの情報は文字で残す。所属の青・緑・金・赤、未発見情報、操作の意味を図柄だけに委ねない。

## 素材と再加工

- `image/` はゲームが読み込む表示素材、`artwork/` は採用素材の原画と切り出し・再配置設定を置く。
- 切り出し位置はJSONを正とし、Markdownの説明と対応させる。図柄の色・透明度を保ち、縦横比を維持して最近傍で縮小する。
- 地図の再配置は `scripts/packMapSprites.cjs`、UIの切り出しは `scripts/extractUIAtlas.cjs` を使う。制作時のみSharpを利用できるNode環境が必要で、ゲーム実行時のビルドは不要。
- 実際の描画は `tests/mapArtPreview.html` と `tests/uiArtPreview.html` で確認する。地図は各縮尺と地形の接続、UIは小さい表示と拡大表示、実際のボタンや資源欄で判読できることを基準にする。
