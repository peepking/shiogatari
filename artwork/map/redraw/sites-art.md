# 探索地点・盾・灯火のマップ図柄

海図・祭壇・入り江・鐘・防衛盾・霧中の灯火の6種は、長辺40pxで道具・石・水面の構造を読める形にする。画風は [共通アート方針](../../README.md) に合わせる。

- 原画: `artwork/map/redraw/sites-atlas.png`
- 画像: 1536×1024、3列2段、透過RGBA。各セルは512×512。
- 再配置設定: `artwork/map/redraw/pack.json`。セル内の輪郭を測定し、最近傍で本番アトラスへ収める。

## モチーフと配置

| 位置 | ID | モチーフ |
| --- | --- | --- |
| 上段左 | rumor | 巻いた角を持つ生成りの海図。青い海岸線と赤い×印。 |
| 上段中央 | altar | 二段の石壇と丸みのある石碑。大きなミント色の波の浮彫。 |
| 上段右 | inlet | 三つの岩が三日月形に囲む青緑の入り江。小さな苔色の低木と砂縁。 |
| 下段左 | bell | 吊り輪・広がった裾・内側の空洞を読める真鍮の鐘。足元に海藻と小石。 |
| 下段中央 | shield | 青と生成りの四分割を施した盾。真鍮の縁と小さな鉄の中央金具。 |
| 下段右 | lantern | 輪の取っ手・青いガラス・暖色の灯を持つ真鍮のランタン。木の筏と縄。 |

図柄は少し上から見た角度に統一する。石は `#9aaba8` / `#617979`、真鍮は `#c5a460`、布と紙は `#ddcb9e`、海は `#245876` / `#4b9eaa`、苔は `#456246` を基調とする。

祭壇は炎・水晶・発光で表さず、海の波を主題にする。鐘の吊り輪と本体、ランタンの取っ手・屋根・胴・底を自然につなげ、細かい装飾や広い背景を含めない。各縮尺での表示は `tests/mapArtPreview.html` で確認する。
