# 森・山岳のマップ図柄

森・山岳の4種は、40pxでも樹種や稜線の違いを読める形にする。画風・粒度・素材の陰影は [共通アート方針](../../README.md) に合わせる。

- 原画: `artwork/map/redraw/landscape-atlas.png`
- 画像: 1254 × 1254 px、透過RGBA、2列 × 2行
- 切り出し・再配置: `artwork/map/redraw/pack.json`

## 切り出し位置

セルは各627 × 627 px。以下の範囲を `pack.json` に記録し、本番アトラスへの再配置に使用する。表示時はアトラスの実測範囲を原寸で保持し、縦横比を維持して各縮尺のマスへ描画する。

| 対象 | セルの範囲 x, y, 幅, 高さ | 図柄範囲 x, y, 幅, 高さ |
| --- | --- | --- |
| forest / 落葉樹3本 | 0, 0, 627, 627 | 48, 69, 553, 528 |
| mountain / 岩峰2つ | 627, 0, 627, 627 | 636, 139, 589, 458 |
| forestAlt / 針葉樹3本 | 0, 627, 627, 627 | 48, 648, 543, 500 |
| mountainAlt / 低い岩稜3つ | 627, 627, 627, 627 | 631, 780, 594, 334 |

## 形と色

落葉樹・針葉樹とも、中央と左右に樹冠と幹を3組配置し、根元まで対応させる。岩峰は左の大峰と右の小峰、岩稜は中央と左右の低い峰を描き、各稜線と明暗面を根元まで連続させる。

葉は苔の緑 `#80925b`、オリーブ `#637a48`、深い緑 `#456246`、岩は青灰 `#9aaba8` / `#617979` を基調とする。幹は茶色、大峰の雪は控えめな生成り色。各図柄の足元は狭くまとめ、半透明の霞や地面タイルを含めない。

原寸と最近傍補間による拡大は `tests/mapArtPreview.html` で確認する。40pxで森・針葉樹林・山岳・低い岩稜を区別できることを基準にする。
