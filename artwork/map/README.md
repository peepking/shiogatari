# 地図の画像素材

地図の地形・拠点・現在地・探索地点・賞金首・物語・出来事・ピンの現行の画風と素材構成を定める。全体の色・素材・モチーフは [共通アート方針](../README.md) を参照する。

## 現在使用するドット絵素材

### 原寸での判読性と構造

樹冠と幹、稜線と岩肌、帆とマストと船体が実寸でもつながる形を優先する。街は城壁の内側に赤屋根の家々をまとめ、戦場跡は赤い旗・丸い木盾・剣・鉄兜、祭壇はミント色の波を刻んだ石碑と石壇で表す。全体表示でも同じモチーフを残す。

図柄ごとの仕様と原画は次を参照する。

- [森と山岳](redraw/landscape-art.md)
- [村・港と船](redraw/maritime-art.md)
- [城壁の街](redraw/town-walled-art.md)
- [海図・祭壇・入り江・鐘・盾・灯火](redraw/sites-art.md)
- [戦場跡](redraw/battlefield-art.md)

### 基本素材と描画方式

既存ユニットの歩兵・弓兵・騎兵のGIFと合わせ、細かな質感を大きな色面と2〜4段階の陰影へ整理する。

- `image/map/sprites-pixel.png`: 1024×1536、RGBA、24図柄。街・村・無法港・帆船・旅人・難破船・漂流物・戦場跡・海図・祭壇・入り江・宝箱・賞金首・五列強・海賊王・魚群・鐘・出来事・星・盾・森2種・山2種。各図柄の位置と実寸は `src/world/mapSpriteBounds.js` に記録し、配置順に依存せず切り出す。
- `image/map/party-norse-pixel.png`: 1254×1254、RGBA。鉄の鼻当て付き兜・丸い木盾・短いマント・旅装の3人を描く。陸の現在地はこの単独原画を使い、アトラス内にも同じ一行を配置する。輪郭範囲は `[111, 251, 1047, 889]`。全体表示も同じ服・兜・丸盾で表す。
- `image/map/terrain-pixel.png`: 1536×1024、三列二段。上段は深海・浅瀬・草地、下段は森の地面・岩地・甲板。青と青緑、落ち着いた緑、暖かい木の色で統一する。
- `image/map/events-pixel.png`: 2172×724、RGBA、三列一段。左から嵐の置き土産・霧中の灯火・沈みかけた宝船。
- `image/map/dangerous-seas-pixel.png`: 1774×887、二列一段。南西は緑灰の斜めの白波、南東は藍の潮流と段状の霧。描画時の色合成に頼らず、原画で海域の色を分ける。

図柄は実測範囲を原寸のまま一度だけ切り出し、周辺・拡大の各表示サイズへ一度だけ縮小する。星・防衛盾の色替えも原寸で行う。長辺40画素への固定縮小を挟まないため、拡大時も屋根や城壁などの細部が残る。画像の補間は止めてドットの輪郭を保つ。地形と荒海も原寸で継ぎ目を合わせ、表示サイズへ一度だけ縮小する。四マス周期の配置は維持する。海岸線の外角・内角、水深の透過マスク、孤島の背景は既存の滑らかな接続を共有し、素材だけの粒度と分けて扱う。全体表示はすべて専用の簡易図柄を使い、詳細表示の同じ素材を過度に縮めない。地図の枠・ボタン・現在地表示も紙と真鍮の色へ合わせる。

## 地形・荒海

通常地形は各512画素パネルを約256論理画素相当の細かなドットで表す。波・草・地面・木目は落ち着いた配色とし、独立した図柄を読み取れるようにする。海と浅瀬の白い波線は控えめな明るさとコントラストで、それぞれ青・青緑になじませる。

深海は `#245876`、浅瀬は `#4b9eaa`、草地は `#80925b`、岩地は `#7f9291`、甲板は暖かい栗色を基調とする。地形模様に岸・島・樹冠・建物を含めず、海岸は描画処理で接続する。

荒海は二つの等しい正方形パネル、各四マス周期とする。約128論理画素の段状の波頭、2〜4段階の陰影、8〜12色を目安に、南西は緑灰 `#30564c` / `#254c45` と泡 `#c3d6c6`、南東は藍 `#354765` と霧 `#8caeba` を使う。対向辺がつながる全面不透明の模様とし、物体・大きな渦・微細な粒・ぼかしを含めない。

基本四枚の読み込みが揃うまでは図形描画を使い、画像の一部だけが切り替わる状態を避ける。失敗時も図形描画を継続する。荒海模様は危険海域専用の追加画像として読み込む。

## 原画と再配置

`redraw/pack.json` から `node scripts/packMapSprites.cjs artwork/map/redraw/pack.json` で本番の図柄・出来事の二枚を再配置できる。制作時のみSharpが必要で、ゲーム実行時の追加依存はない。

`redraw/sprites-before-redraw.png` は漂流物・宝箱・賞金首・五列強・海賊王・魚群・出来事・星の原画、`redraw/events-before-redraw.png` は嵐の置き土産の原画として使う。賞金首のUIも同じ原画を [共用設定](../ui/atlases/map-bounty.json) から切り出す。

再配置結果の範囲は `redraw/packed-bounds.json` へ出力する。描画で使う `src/world/mapSpriteBounds.js` の範囲もこの結果と揃える。

## 表示の確認

全分類・全縮尺・海岸・危険海域・既存ユニットとの比較は `tests/mapArtPreview.html` で確認できる。

全27図柄を実マス32px・周辺約37px・拡大約78px、長辺78pxの図柄と2倍表示、全体13pxと4倍表示で比較する。全体マップは `src/world/mapOverviewArt.js` の専用図柄を使い、地点の輪郭と依頼ピンの形・色を小さなマスでも残す。
