# UIの船・潮の施設のピクセル絵

船は帆装・船体・櫂・船楼・盾・漁具の大きな違いで区別し、潮の施設は発展段階と共通の波紋章を表す。色・素材・粒度は [UIの共通方針](README.md) に合わせる。

## 原画と表示素材

- 船11種と潮の施設5段階の原画: `artwork/ui/atlases/ships-tides.png`。1448×1086、RGBA、4列4段。
- 船の表示素材: `image/ui/ship-{caravel,knarr,longship,cog,galley,carrack,galleass,galleon,fluyt,fishing_boat,viking_ship}.png`
- 潮の施設: `image/ui/tide-stage-{0,1,2,3,4}.png`
- 切り出しの範囲とサイズ: `artwork/ui/atlases/ships-tides.json`
- 切り出し: `scripts/extractUIAtlas.cjs`。指定範囲から透過で切り出し、船・施設とも128×128で表示する。漁船は原画内の128×128の画素をそのまま使う。

船は `src/fleet/shipArt.js`、潮の施設は `src/faith/tideScene.js` の共通描画を使い、SVG内の画像として表示する。24px・32pxでも形の違いを読めることを基準にする。

## 船のモチーフ

| 船種・素材ID | 主な形 |
| --- | --- |
| キャラベル / caravel | 低い木の船体と、生成りの三角帆2枚。 |
| クナール / knarr | 深い船腹、四角帆1枚、甲板の樽。 |
| ロングシップ / longship | 細い船体、四角帆1枚、櫂と赤・金の丸盾。 |
| コグ / cog | 重い貨物船体、大きな四角帆1枚、角張った船尾楼。 |
| ガレー / galley | 細長く低い船体、三角帆2枚、多数の櫂。 |
| キャラック / carrack | 丸みのある船腹、三本マスト、四角帆と小さな三角帆、前後の船楼。 |
| ガレアス / galleass | 幅のある重い戦闘ガレー、四角帆2枚、船尾楼と櫂。 |
| ガレオン / galleon | 大きな船体、三本マストの四角帆、高く段状の船尾楼。 |
| フリュート / fluyt | 膨らんだ船腹、狭い甲板、丸みのある高い船尾、四角帆。 |
| 漁船 / fishing_boat | 低い船体、小さな三角帆、オリーブ色の網と魚籠。 |
| ヴァイキングシップ / viking_ship | 赤と生成りの縞の四角帆、竜頭の船首、櫂と丸盾。 |

漁船の網は船体に沿わせ、紐で船首に結び、下端が水面に触れる位置に置く。船の帆・マスト・櫂・縄はまとまった輪郭の内側に収め、細かな索具より船種の違いを優先する。

## 潮の施設

全段階でミントグリーンの海の波紋章を使う。炎・焚き火・十字架は使わない。

| 段階・素材ID | モチーフ |
| --- | --- |
| 0 / tide-stage-0 | 木の柱で支えた生成りの天幕、丸太の腰掛け、波の旗を持つ集い。 |
| 1 / tide-stage-1 | 急な屋根と木の柱を持つ小さな祠。入口の上に波の紋章。 |
| 2 / tide-stage-2 | 正面に波を刻んだ石の祭壇。背後に木の支柱と生成りの布。 |
| 3 / tide-stage-3 | 石の基礎と高い木の屋根を持つ寺院。入口の上に大きな波の紋章。 |
| 4 / tide-stage-4 | 段状の石屋根、柱で囲んだ広い入口、上部の波紋章を持つ石造神殿。 |

天幕・木造の祠・石壇・木造寺院・石造神殿の順に規模と構造を発展させる。各段階の表示は `tests/uiArtPreview.html` で確認する。
