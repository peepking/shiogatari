# 資源・物資のピクセル絵

資源・物資は20〜24pxで主題が分かる輪郭にする。色・素材・粒度は [UIの共通方針](README.md) に合わせる。

## 原画と切り出し

- 17種の原画: `artwork/ui/atlases/resources.png`。1122×1402、RGBA、4列5段。
- 切り出し設定: `artwork/ui/atlases/resources.json`。
- 唐辛子の原画・設定: [共用原画](studies/README.md)、`artwork/ui/atlases/approved-samples.json`。
- 表示素材: `image/ui/*.svg`。基本128×128の透過PNGを埋め込み、viewBoxは24×24。

`node scripts/extractUIAtlas.cjs artwork/ui/atlases/resources.json` で再切り出しする。部隊と信仰は最大の連結領域を選び、隣の図柄の混入を除く。織物は原画内の128×128の範囲をそのまま使う。その他は透明な余白を整理し、縦横比を維持して最近傍で収める。
