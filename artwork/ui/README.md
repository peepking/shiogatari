# UIのアイコン

中世北欧・西洋の旅の道具や紋章を、実寸で分かる輪郭と大きな色のまとまり、素材の陰影で統一する。共通の画風は [アート方針](../README.md)、地図の図柄は [地図素材](../map/README.md) を参照する。

## 共通の色と粒度

- 濃い紺の輪郭、クリームの羊毛、真鍮の金、木の茶、赤い外套、苔の緑、青灰の鉄を使う。
- 約48〜56pxの論理粒度を目安に作画。静的SVGには基本128pxの透過PNGを埋め込み、20px前後で主題が分かる輪郭を使う。マップと共用する賞金首は176×207pxの切り出し画素を保持する。拡大時は補間しない。
- 信仰は明るいミントグリーン（`#7dffb2`系）の海の波。炎を使わない。部隊員は3人組。香辛料は赤い唐辛子。食料は小麦の穂だけとし、資金は直径を揃えた金貨を使う。織物は白い縁取りを付けない青い布で表す。
- 所属を表す青・緑・金・赤は区別を残す。数量・名称・状態・読み上げの表示はアイコンに置き換えない。

## 対応範囲

- 資源・物資18種: 船、部隊、信仰、物資、資金、名声、食料、木材、石材、鉄、繊維、塩、香辛料、武具、織物、酒、革、海図。
- 禁制品4種: 違法薬物は薬草と粉末の小包、密造酒は陶器の酒壺、盗品工芸品は宝石の金杯、盗品武具は布を巻いた斧。通常品と専用図柄を分ける。
- 行動20種と所属盾1種: 釣り、依頼、待機、防衛、封鎖、降伏、退出、賞金首、裏の行動、謁見、窓口、釣り小屋、魚図鑑、最終航海、探索、大会戦、海域イベント、救助、造船所、交易。用途ごとに割り当て、釣りと魚図鑑や難破船の3選択も区別する。
- 四季4種: `season-spring.svg`、`season-summer.svg`、`season-autumn.svg`、`season-winter.svg`。日付ヘッダで季節を表す。
- 勢力4種・貴族6種: `image/factions/`、`image/nobles/`。北海連合・群島同盟・湾岸城塞群は青・緑・金の盾型紋章、外洋海賊は海賊旗。勢力一覧、所属表示、謁見、賞金首の所属に適用する。
- 船11種: `src/fleet/shipArt.js`。帆装・櫂・船楼・盾・漁具を区別し、船団・造船所・図鑑で共用する。
- 信仰施設5段階: `src/faith/tideScene.js`。ミント色の波の紋章を共通に、集いから木造の祠、祭壇、寺院、石造神殿へ描き分ける。
- 魚図鑑4種: `src/fishing/fishingCodexArt.js`。一般魚・大物・超大物はSVGのシルエットで表す。未発見は点線の円と疑問符とし、分類を明かさない。

賞金首の行動アイコンは、街のボタン・通常海域と危険海域の現地確認でマップと同じ手配書を共用する。切り出し設定は `atlases/map-bounty.json`。

資源・取引・依頼・結果で同じ素材を使い、ファイル名と公開描画関数を共通の参照先とする。

全77種類の小さい表示・拡大表示と実際の行動ボタンは `tests/uiArtPreview.html` で確認できる。

## 原画と再切り出し

原画と切り出し設定は `artwork/ui/atlases/` に置く。素材ごとのモチーフ・用途・サイズは次を参照する。

- [資源・物資](resources-art.md)
- [行動](actions-art.md)
- [海賊旗・人物・四季](heraldry-art.md)
- [勢力3種の盾型紋章](faction-crests-art.md)
- [船・潮の施設](dynamic-art.md)
- [所属盾・唐辛子・禁制品の共用原画](studies/README.md)

各JSONは切り出し範囲を定める。Sharpを利用できるNode環境で `node scripts/extractUIAtlas.cjs artwork/ui/atlases/resources.json` のように実行する。再切り出しでは原画の色・透明度を保ち、切り出し・余白の整理・最近傍での表示サイズ調整を行う。ゲームの実行時にSharpやビルドは不要。
