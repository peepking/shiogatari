# 勢力別賞金・無法港拡張 草案

状態：未実装。別workでの実装検討用草案。

ユーザー回答を反映した実装用設計は [勢力別賞金・無法港拡張 設計書](faction-bounty-expansion-design.md) を参照。本書は原案として保持し、競合時は設計書の確定事項を優先する。

関連仕様：

- [賞金首システム仕様書](bounty-system-design.md)
- [無法港・海賊勢力 追加設計書](pirate-havens-design.md)
- [全体設計](design.md)

本書は既存のプレイヤー手配を勢力別へ拡張し、犯罪による短期的利益、通常勢力からの追跡、無法港を拠点とする犯罪者プレイ、複数の手配解除手段を一つの循環として成立させるための草案である。既存仕様と競合する場合、実装時に本書を正式仕様へ昇格させたうえで関連文書を更新する。

## 1. 目的

- 犯罪を単なる関係値低下ではなく、利益と長期的な不利益を選ぶ行動にする。
- 手配を勢力別にし、ある地域を追われても別勢力圏や無法港で活動を継続できるようにする。
- 賞金額に応じて追跡と施設制限を段階的に強化する。
- 無法港を、通常勢力から追われたプレイヤーの代替拠点および手配解決手段の提供場所にする。
- 600日間犯罪を行わない自然解除以外にも、資金、時間、依頼、勢力関係を代償とする解除方法を用意する。
- 独立した悪名ゲージを増設せず、賞金額を犯罪者としての知名度にも利用する。

## 2. 基本方針

- 手配額、最後の犯罪日、追跡、施設制限、自然解除は勢力ごとに管理する。
- 全勢力の賞金合計は表示と賞金稼ぎの脅威判定に使用するが、個々の施設制限には使用しない。
- 犯罪は有効な選択が成立した時点で記録する。戦闘の敗北、逃走、引き分けでは取り消さない。
- 犯罪前に、対象勢力、予想利益、加算賞金、関係悪化、発生する戦闘を表示する。
- 禁制品の所持・売買だけでは賞金を加算しない。検問で強行突破するなど、明示的な犯罪選択が成立したときに加算する。
- 犯罪系依頼はゲーム開始時から受注可能とし、賞金額を解禁条件にしない。
- 犯罪系依頼の受注を黒ひげの好感度で制限しない。好感度が低下しても、犯罪系依頼の達成によって関係を回復できる導線を常に残す。
- 黒ひげの好感度は、依頼の受注可否ではなく、報酬、手数料、品揃え、雇用などの有利不利に用いる。
- 要注意人物の段階では買取価格を悪化させない。
- 完全な進行不能を避けるため、食料の最低限購入、緊急修理、投降または清算の導線を残す。

## 3. 状態データ原案

プレイヤーの手配状態を、世界共通の1件から勢力別の記録へ移行する。

```js
wanted: {
  byFaction: {
    north: { amount: 2500, lastCrimeAbs: 1234 },
    citadel: { amount: 0, lastCrimeAbs: null },
    archipelago: { amount: 1000, lastCrimeAbs: 1200 },
    pirates: { amount: 500, lastCrimeAbs: 1220 }
  },
  history: [
    { kind: "merchant_attack", factionId: "north", amount: 1000, day: 1234 }
  ]
}
```

- `byFaction` は勢力IDをキーとする。
- 各記録は現在賞金と最後の犯罪絶対日を保持する。
- 犯罪履歴には犯罪種別、対象勢力、加算額、成立日を保存する。
- 履歴は既存どおり直近50件を上限とし、手配解除後も保持する。
- 合計賞金は保存せず、各勢力の現在賞金から算出する。
- 対象勢力を決定できない不正データでは、別勢力や世界共通賞金へ振り替えない。

### 旧セーブ移行原案

既存の世界共通賞金には対象勢力の内訳がないため、過去の犯罪履歴に有効な勢力IDが保存されていない限り、恣意的な按分を行わない。

候補は実装時に次のいずれかへ確定する。

1. 既存の世界共通賞金を「旧手配」として自然解除まで追跡だけに使用し、新しい犯罪から勢力別へ移行する。
2. 既存の世界共通賞金を0へ補完し、過去の犯罪を遡及推定しない。

既存仕様の「旧セーブへ犯罪を遡及付与しない」方針との整合から、初期案は2を推奨する。正式決定時は移行による影響を更新履歴へ明記する。

## 4. 犯罪と加算先

### 4.1 既存犯罪

| 犯罪 | 成立時点 | 加算先 | 賞金原案 |
| --- | --- | --- | ---: |
| 商人襲撃 | 有効な襲撃選択の確定時 | 商人の所属勢力 | 1,000 |
| 商人救助からの襲撃 | 有効な襲撃選択の確定時 | 商人の所属勢力 | 1,000 |
| 難民襲撃 | 有効な襲撃選択の確定時 | 難民の所属勢力 | 1,500 |
| 検問強行突破 | 有効な突破選択の確定時 | 検問担当勢力 | 2,000 |
| 海賊依頼への加担 | 依頼報酬の受取時 | 生成時に固定した被害勢力 | 500～1,500 |

海賊依頼は依頼種別と被害規模に応じて賞金を変える。配達や納品は低く、隊商・商船団襲撃は高くする。生成時に対象勢力と加算賞金を固定し、受注後の占領や関係変化で再計算しない。

### 4.2 拠点での窃盗

通常拠点に、季節ごとに1回まで実行できる窃盗行動を追加する。

| 対象 | 主な利益 | 賞金原案 | その他の影響 |
| --- | --- | ---: | --- |
| 市場 | 少量の資金・交易品 | 500 | 拠点支持度と担当貴族好感度が小幅低下 |
| 兵糧庫 | 食料・資材 | 1,000 | 拠点支持度と担当貴族好感度が低下 |
| 武器庫 | 高価な物資・希少品 | 1,500 | 守備隊との戦闘、関係が大幅低下 |

- 実行時に対象勢力へ賞金を加算する。
- 勝敗にかかわらず窃盗の季節枠を消費する。
- 利益の確定時点と戦闘報酬を分離し、再読込や二重クリックで再取得できないようにする。
- 無法港で同種の行動を実行した場合は海賊勢力への犯罪とする。

### 4.3 商船・隊商襲撃の拡張

- 護衛規模が大きいほど、予想戦利品と加算賞金を増やす。
- 襲撃選択時に最低限の利益を確定し、勝利時に追加の積荷を得る構成を候補とする。
- 対象勢力、敵推定人数、予想戦利品、賞金加算額を選択前に表示する。
- 逃走または敗北しても成立済みの犯罪は残る。

### 4.4 通常拠点への襲撃

高リスクの能動行動として、通常拠点を略奪して撤退する行動を追加する。

- 守備隊との固定戦闘を開始する。
- 勝利時に拠点在庫の一部、資金、物資、捕虜などを得る。
- 対象勢力へ3,000～8,000の賞金を加算する。
- 対象拠点の支持度と担当貴族好感度を大幅に低下させる。
- 一定期間、その拠点を利用不能にする。
- 国家戦争の占領処理は行わず、「略奪して撤退する」行動として分離する。

### 4.5 将来候補

- 捕虜の脱走幇助：対象勢力への賞金と引き換えに、捕虜解放または海賊兵加入。
- 港湾税の踏み倒し：小額の利益と小額の賞金、再入港時の不利益。
- 正規軍への先制攻撃：対象勢力へ賞金を加算。
- 無法港での窃盗や海賊関係者への襲撃：海賊勢力へ賞金を加算。

## 5. 賞金額による通常勢力の対応

施設制限は、現在地を支配する勢力からの賞金だけで判定する。他勢力からの賞金や合計賞金を流用しない。

| 対象勢力の賞金 | 状態 | 主な影響 |
| ---: | --- | --- |
| 0 | 手配なし | 全施設を通常利用可能 |
| 1～999 | 要注意人物 | 移動中・入港時の検問率上昇。買取価格は変化させない |
| 1,000～2,999 | 指名手配 | 貴族面会、通常依頼の新規受注、通常兵の雇用を制限 |
| 3,000～5,999 | 重罪人 | 通常取引と造船購入を制限し、修理費を割増 |
| 6,000以上 | 入港拒否 | 港外で投降、清算、賄賂、強行突破を選択 |
| 10,000以上 | 大物賞金首 | 精鋭賞金稼ぎの出現率または編成を強化 |

閾値と制限内容は初期案であり、既存経済とプレイテストを通じて定数調整する。

### 施設制限の安全策

- 食料の最低限購入は、割増料金または数量制限付きで残す。
- 航行不能を避ける緊急修理を残す。
- 投降または清算の窓口は入港拒否中でも港外から利用可能にする。
- すでに受注済みの通常依頼を即時失敗にはしない。達成報告の可否と期限処理を別途定義する。
- 名誉家臣であっても、自勢力への犯罪と賞金を免除しない。一定額以上で家臣機能の停止または除名候補とする案を別途検討する。

## 6. 無法港での扱い

### 6.1 通常勢力からの賞金

- 通常勢力からの賞金は、無法港の基本施設利用を制限しない。
- 通常勢力からの合計賞金は、犯罪者としての知名度を示す表示や上位サービスの目安に使用できる。
- 犯罪系依頼は合計賞金0でも最初から受注可能とする。
- ゲーム開始直後に犯罪系依頼を受けるため、先に窃盗や村襲撃を行う必要はない。

### 6.2 犯罪系依頼と黒ひげの好感度

犯罪系依頼は、黒ひげの好感度にかかわらず常に受注可能とする。これにより、好感度が低下しても依頼達成で関係を回復できる。

黒ひげの好感度には、次の用途を持たせる。

- 依頼報酬の増減。
- 偽造、密輸仲介、賞金減額などの手数料。
- 禁制品や希少品の品揃え。
- 海賊系部隊の雇用人数、雇用費、利用できる兵種。
- 黒ひげとの固有会話、贈答、特別な情報。

好感度が最低でも犯罪系依頼そのものは閉鎖しない。好感度による不利益は、依頼報酬減少や高い手数料など、回復行動を妨げない範囲に限定する。

名誉家臣による犯罪系依頼の扱いは既存仕様を維持する候補とする。ただし、受注禁止を維持する場合でも、名誉家臣を辞する導線と理由表示を必須とする。

### 6.3 海賊勢力からの賞金

- 無法港での施設制限は、通常勢力の賞金ではなく海賊勢力からの賞金で判定する。
- 海賊勢力への犯罪には、無法港での窃盗、海賊依頼人への裏切り、海賊関係者への明示的な襲撃などを含める。
- 海賊勢力から高額の賞金を懸けられた場合も、解除・投降・仲介の最低限の導線は残す。

## 7. 600日以外の手配解除

各解除方法は対象勢力を1つ選び、その勢力の賞金だけに作用する。他勢力の賞金、拠点支持度、貴族好感度は自動回復させない。

### 7.1 賠償金の支払い

- 支払額は対象勢力の現在賞金の150%を初期値とする。
- 支払い後、その勢力の賞金を0にする。
- 支持度、貴族好感度、犯罪履歴は回復・消去しない。
- 高額手配中でも港外の清算窓口から実行できる。
- 犯罪利益より清算費用が安くならないよう調整する。

### 7.2 投獄を受け入れる

- 資金が不足した場合にも利用できる解除手段とする。
- 賞金額に応じて30～120日経過させる。
- 禁制品を没収する。
- 資金、交易品、物資の一部を没収する候補とする。
- 対象勢力の賞金を半減または全額解除する。
- 依頼期限、季節更新、維持費など、時間経過による既存処理を適用する。
- 経過日数と没収内容は確定前に表示する。

### 7.3 恩赦依頼

対象勢力のために危険な仕事を行い、賞金を減額する。

候補：

- 海賊船団の討伐。
- 捕虜または要人の救出。
- 軍需物資の納品。
- 前線防衛。
- 対象勢力が指定する賞金首の討伐。

恩赦依頼は通常依頼の受注制限とは別の港外窓口から受注可能にする。達成時に固定額または現在賞金の一定割合を減らし、複数回で完全解除できる構成を基本とする。

### 7.4 無法港での身分偽造

- 対象となる通常勢力を1つ選ぶ。
- 黒ひげの好感度によって手数料を増減するが、好感度を利用可否の必須条件にはしない。
- 対象勢力の賞金を半減する。
- 再利用には長い待機期間を設ける。
- 失敗抽選を導入する場合は、確率と失敗時の賞金増加を事前表示する。
- 賠償金より安価になり得る代わりに、全額解除できず、再利用制限または発覚リスクを持つ。

### 7.5 密告・司法取引

- 海賊側の情報、依頼、禁制品などを通常勢力へ引き渡す。
- 選んだ通常勢力の賞金を大幅に減らす。
- 黒ひげの好感度を大幅に低下させる。
- 内容に応じて海賊勢力からの賞金を加算する。
- 通常勢力へ戻る代わりに無法港との関係を悪化させる勢力転換として扱う。
- この結果でも犯罪系依頼は受注不能にせず、後から黒ひげの好感度を回復できるようにする。

### 7.6 特赦

- 戦争終結、国難解決、貴族交代などに伴う希少イベントとする。
- 対象勢力の賞金を全額または一定額まで減らす。
- 常用できる解除方法にはせず、世界情勢へ参加した報酬として扱う。

### 7.7 自然解除

- 勢力ごとに、最後の対勢力犯罪から600日経過した時点でその勢力の賞金を0にする。
- 別勢力への犯罪では解除期限を更新しない。
- 自然解除でも犯罪履歴、支持度、貴族好感度は回復しない。

## 8. 追跡と賞金稼ぎ

- 正規軍の追跡は、現在地に近い通常拠点の勢力から賞金を懸けられている場合だけ発生する。
- 自勢力の名誉家臣であっても、その勢力から手配されていれば追跡免除しない案を基本とする。
- 賞金稼ぎは勢力を問わず、全勢力の合計賞金を基準に出現率と強さを決める。
- 賞金稼ぎを撃退しても賞金を減らさない。撃退だけで解除できると、高額手配の代償が短期戦闘だけになるためである。
- 同じ移動で正規軍追跡と賞金稼ぎが重複しないよう、遭遇優先順位を定義する。

## 9. 表示

賞金首一覧のプレイヤー欄に、勢力別手配と合計賞金を表示する。

表示例：

```text
あなた　合計賞金 4,000

北方諸侯　2,500　指名手配
城塞領　　　  0　手配なし
島嶼連合　1,000　指名手配
外洋海賊　  500　要注意人物
```

- 各勢力について、現在段階、次の制限までの額、自然解除予定時期を表示する。
- 犯罪履歴には、日付、罪状、対象勢力、加算額を表示する。
- 犯罪選択前に、加算賞金と即時の施設制限段階変化を表示する。
- 拠点入口では、利用可能施設、制限理由、選択可能な解除手段をまとめて表示する。
- 無法港では、通常勢力の合計賞金、海賊勢力からの賞金、黒ひげの好感度を別々に表示する。

## 10. 実装単位原案

### 第1段階：勢力別手配基盤

- 手配状態と犯罪履歴へ勢力IDを追加する。
- 既存犯罪の加算先を勢力別へ変更する。
- 勢力ごとの自然解除を実装する。
- 追跡判定と賞金首一覧を勢力別へ変更する。
- 保存・復元・旧セーブ補完を追加する。

### 第2段階：施設制限と清算

- 賞金段階の共通判定を追加する。
- 通常拠点と無法港の施設制限を接続する。
- 賠償金、投獄、恩赦依頼の入口を追加する。
- 最低限購入、緊急修理、港外清算を保証する。

### 第3段階：犯罪行動

- 拠点窃盗を追加する。
- 商船・隊商襲撃の報酬と表示を拡張する。
- 通常拠点襲撃を追加する。
- 犯罪ごとの一意IDと二重反映防止を整備する。

### 第4段階：無法港の拡張

- 身分偽造を追加する。
- 密告・司法取引を追加する。
- 黒ひげの好感度を報酬、手数料、品揃え、雇用条件へ反映する。
- 犯罪系依頼が賞金0・好感度最低でも受注可能であることを保証する。

## 11. 主な検証項目

- 同じ犯罪が一度だけ、正しい対象勢力へ加算される。
- 戦闘の敗北、逃走、引き分けで成立済み犯罪が取り消されない。
- 海賊依頼の対象勢力と賞金が生成後に変化しない。
- ある勢力への犯罪が、別勢力の解除期限と施設利用へ影響しない。
- 599日では解除されず、600日で対象勢力だけ解除される。
- 要注意人物になっても買取価格が悪化しない。
- 賞金0かつ黒ひげ好感度が初期値でも犯罪系依頼を受注できる。
- 黒ひげ好感度が最低でも犯罪系依頼を受注し、達成によって回復できる。
- 通常勢力から高額手配されても、無法港の基本施設を利用できる。
- 海賊勢力から手配された場合だけ、無法港側の制限が発生する。
- 入港拒否中でも食料、緊急修理、投降、清算の導線が残る。
- 賠償、投獄、恩赦、偽造、司法取引が選択した勢力だけに作用する。
- 手配解除後も犯罪履歴が保持され、支持度と貴族好感度が自動回復しない。
- 賞金稼ぎ撃退で賞金が減らない。
- 旧セーブの世界共通賞金を誤って複数勢力へ重複加算しない。
- 保存と再読込で犯罪、支払い、報酬、解除が二重適用されない。

## 12. 実装前に確定する項目

- 旧セーブの世界共通賞金を破棄するか、一時的な旧手配として残すか。
- 海賊依頼の種別ごとの加算賞金。
- 施設制限の閾値と、各段階で利用可能な最低限機能。
- 名誉家臣が所属勢力から手配された場合の資格停止・除名条件。
- 通常拠点襲撃の再実行間隔と、拠点在庫・戦況への影響。
- 投獄の日数、没収対象、賞金減額率。
- 恩赦依頼の生成方法と、受注中の通常依頼との共存。
- 偽造の費用、待機期間、発覚判定を採用するか。
- 合計賞金による賞金稼ぎの出現率と編成強化。
