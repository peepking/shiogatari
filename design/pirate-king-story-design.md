# 海賊王の海図・海没神話

状態：実装済み。噂・六人の順次討伐・専用海図・海賊王との連戦・報酬船・海没神話に対応する。未指定の調整値には初期値を採用し、本書へ記録する。

関連仕様：[最終航海・航海統計](final-voyage-design.md)、[探索・海図・艤装](expansion-design.md)、[戦闘基盤再設計](battle-redesign.md)、[賞金首・固有船](bounty-system-design.md)、[船種・造船所](shipyard-design.md)、[無法港・海賊勢力](pirate-havens-design.md)。

## 1. 目的と合意済みの流れ

海没神話を、噂・順次討伐・専用海図の完成・海賊王との連戦で解放する物語にする。通常の海図や賞金首を遊びながら進められる任意の長期目標とする。

1. 名声が1,000を超えた状態で村・街・無法港へ入ると、海賊五列強の噂がまれに発生する。
2. 噂が発生すると、対象の海賊がマップへ出現する。
3. 出現順はビョルン → エイリク → イーヴァル → ラグナル → シーヴァルド → トルケル。現在の対象を倒すまで次の噂は発生しない。
4. 各対象を倒すと「海賊王の海図」の破片を1枚得る。
5. 六人を倒して海図を完成させると、マップ中央付近の海タイルへ海賊王オーラヴが出現する。
6. 海賊王との2連戦に勝利するとヴァイキングシップを得て、海没神話を解放する。

回答済みの事項：

- 登場人物は六人だが、呼称は「海賊五列強（六人）」のままにする。内部データは六人を個別IDで扱う。
- 海賊王の2戦目は合計300人。前衛200人、予備隊100人とする。
- 1戦目と2戦目の間に準備画面で編成を変更できる。
- 2戦目で敗北した場合、次の挑戦は1戦目からとなる。
- 噂は拠点ごとの季節初回の入場で10%。確率は後から一か所で変更できる設定値にする。
- 五列強の固有船は各討伐の確定報酬として1隻ずつ獲得する。指定容量は基礎船種への追加値とする。
- 海賊王の海図は海図達成数・探奥神話の条件に含めない。

敗北した主人公を強制的に海没させる仕組みではない。実際の解放条件は海賊王の討伐成立とし、勝者が分からないという内容は後世の語り口で表現する。結末の閲覧後も既存の最終航海と同様にプレイを続けられる。

## 2. 噂の発生条件と調整

噂の発生率はユーザー確認済みの10%。対象となる拠点ごとに季節初回の入場で抽選する。通常海図の噂は現行の5%を維持し、物語の噂だけを別の設定値で調整する。

確率は `src/pirates/pirateKingConfig.js` の `PIRATE_KING_CONFIG.rumorChance` に集約し、初期値を `0.10` とする。抽選側はこの設定を参照し、UIや保存処理に10%を重複定義しない。後の調整では設定値だけを変更できる。確率をセーブへ固定せず、変更後の未実施の抽選から新しい値を使う。同季節の実施済み抽選や保存済みの当選・出現状態は再抽選しない。

| 項目 | 仕様 |
| --- | --- |
| 名声 | `state.fame > 1000`。ちょうど1,000では発生しない |
| 場所 | 村・街・無法港への入場が成立した時点。通過・マップ選択・画面の再描画・入場拒否では抽選しない |
| 発生率（確認済み） | 設定値 `rumorChance`。初期値10% |
| 頻度 | 対象となる拠点ごとに、同じ季節は1回だけ抽選。不発も保存する |
| 抽選対象 | 未討伐の先頭一人だけ。出現済みの対象がいる間、海図完成後、海賊王討伐後は抽選しない |
| 通常海図との関係 | 独立抽選。通常海図の噂や購入イベントを置き換えない |
| 名声低下 | 次の噂には再び1,000超が必要。出現済みの対象・取得した破片は消さない |
| 討伐直後 | 次の対象をその場で出さない。その後の対象拠点への入場で抽選する |

名声未達・対象出現中の入場は専用の抽選機会を消費しない。条件を満たして抽選した入場だけを拠点ID・季節で記録する。通常海図の抽選記録とは別に保存し、再入場・再読み込みで抽選し直さない。過去のセーブへ巻き戻す操作まで防止するものではない。

既存の入場処理が生成する検問・潮盟・通常海図のイベントと同じキューへ追加する。既存イベントを上書きせず、選択中のイベントや戦闘画面の上へ突然別ダイアログを開かない。

## 3. マップ配置・進行

### 3.1 五列強の配置

六人とも到達可能な海タイルへ配置し、戦場を甲板とする。噂を聞いた拠点からマンハッタン距離10〜15の候補を優先して均等抽選し、適地がなければ海タイルに限って探索範囲を広げる。距離帯も設定ファイルで変更できる。

拠点、既存賞金首、探索地点、通常海図の予約地点、討伐依頼の固定地点と重ねない。後から生成する通常の目標も、物語の予約地点を避ける。配置と敵編成は噂成立時に保存し、再読み込みや名声変化で変えない。

適地がまったくなければ対象を出現済みにはしない。噂の当選を「配置待ち」として保持し、世界の準備後や次の入場で配置だけ再試行する。新たな噂抽選は要求しない。陸タイルへ置く代替は行わない。

### 3.2 対象との接触

- 到着だけでは戦闘を開始しない。「旅の行動」から対象の説明・部隊・固有船を確認し、「討伐の準備」を選ぶ。
- 受注・報告・期限を必要としない。別の依頼を受けていても進められる。
- 対象は固定地点に残り、勝利したときだけ討伐済みになる。敗北・逃走・引き分けでは海図も固有船も付与しない。
- 再挑戦時の敵は全快、編成は同じ。経過日数・季節変更・通常賞金首の補充によって対象を消さない。
- 通常賞金首の同時存在枠とは別に管理する。通常賞金首の期限や貴族好感度の専用精算を自動適用しない。

### 3.3 海賊王の配置

六枚目の破片を受け取る処理で海図を完成させ、追加の噂抽選なしで海賊王を配置する。マップの中央座標を基準に、到達可能で他の目標と重ならない海タイルのうちマンハッタン距離が最も近いものを選ぶ。同距離の候補は行・列の順で固定し、決定した座標を保存する。

中央付近に海がない場合は中央からの探索範囲を広げる。海の候補がない場合は「海図完成・配置待ち」として保存し、破片を失わせない。完成通知では発見地点を明かし、マップの印と依頼欄の場所案内を接続する。

## 5. 海賊王オーラヴとの連戦

### 5.1 兵力

1戦目は海賊ユニットだけの200人・Lv4。2戦目は通常兵を含む大会戦で合計300人・Lv5。詳細配分は以下とする。

| 戦闘・配置 | 人数配分 |
| --- | --- |
| 1戦目・通常戦 | 海賊盾兵40、海賊槍兵40、海賊斧兵40、海賊弓兵30、海賊突撃兵30、略奪騎兵20。合計200 |
| 2戦目・前衛 | 重騎兵30、略奪騎兵30、海賊槍兵40、弩兵40、海賊盾兵30、海賊突撃兵30。合計200 |
| 2戦目・予備隊 | 略奪騎兵80、重騎兵20。合計100 |

2戦目は `battleKind: "grand"` を使い、既存の予備隊投入・盤上人数上限・60tickの制限・勝敗判定・未投入兵の精算除外を共用する。前線の資格、戦況スコア、国力変化、前線依頼の達成処理とは接続しない。甲板上でも既存の騎兵の地形補正を適用し、物語だけの特例で打ち消さない。

### 5.2 連戦と再挑戦

1. 現地で挑戦を選び、1戦目の準備画面を開く。
2. 1戦目に勝利したら、その戦闘の損耗・救護・勝敗統計を精算し、連戦の進行を保存する。
3. 続けて2戦目の準備画面へ進む。残った保有兵から前衛・予備隊を編成し直せる。
4. 2戦目に勝利したら討伐成立。対象を消し、船の獲得と海没神話の解放を一度だけ確定する。
5. 2戦目で敗北したら、連戦の進行を1戦目へ戻す。兵の損耗や戦闘統計を巻き戻すことはない。

逃走・引き分け・連戦からの離脱も連戦失敗とし、再挑戦は1戦目から。連戦間は編成の変更だけを可能とし、入港・雇用・交易などの世界行動へ戻る場合は「準備を取りやめる」で挑戦を終了する。準備の取消は必ず成功し、対象は海に残る。兵不足で2戦目を始められない場合にも離脱できる。

部隊HPは既存と同じく各戦闘開始時に生成する。1戦目の残りHPを2戦目へ持ち越す追加仕様は設けず、恒久損耗した兵数を持ち越す。予備隊投入と支援効果は各戦の開始時点で固定し、1戦目の編成や準備データを2戦目へ誤って再利用しない。

戦闘途中は保存せず、最後に保存した準備状態から再開する。1戦目勝利が保存済みで2戦目の準備・戦闘を中断した場合は、2戦目の準備へ復帰する。これは敗北とは区別し、保存済みの損耗を再適用しない。2戦目の敗北が確定・保存された場合は通常の旅へ戻り、現地から再挑戦すると1戦目の準備になる。

再挑戦による1戦目報酬の反復を避けるため、1戦目勝利では資金・食料・物資・名声・捕虜を付与しない。通常の戦利品は2戦目勝利時の戦闘結果に対してだけ付与し、1戦目の報酬を別に蓄積しない。練度上昇・救護・撃破数・損耗・勝敗は各戦の確定結果を記録し、やり直した戦闘も実際の戦闘として数える。

## 6. ヴァイキングシップ

確定事項：新しい船種。海賊王討伐で獲得し、人数容量＋50、物資容量＋100、全兵員HP＋20%。

実装仕様：

- 内部IDは `viking_ship`。既存船の容量に加算する固有船ではなく、1隻の基本容量が人数50・物資100となる新船種として扱う。
- 討伐成立時に1隻だけ獲得する。通常の造船所補充・ランダム船報酬から除外する。
- HP効果はこの船を保有している間の味方全兵種へ適用する。前衛・投入される予備隊とも対象。敵のHPは増やさない。
- 戦闘開始時の船団効果にHP増加率を保存し、部隊作成時に初期HP・最大HPへ同じ倍率を一度だけ適用する。既存の人数・レベル・戦闘HP倍率を反映した値を `floor(HP × 1.2)` とする。
- 重複保有を想定した効果上限は1隻分とする。容量は隻数分加算し、HP効果だけは最大＋20%。
- 売却・喪失後は次の戦闘からHP効果がなくなる。既に解放した海没神話は取り消さない。
- 船図鑑では海賊王の討伐完了後に公開する。討伐前は項目・船名・能力を表示せず、検索や比較からも公開しない。討伐後の売却・喪失では公開を維持し、新しい旅では再び非公開になる。

調整用の初期定価は20,000資金。船維持費は通常船と同じ定価の2%で、軽減前400資金／季節。造船所で通常の売却率80%（16,000資金）で売却でき、買取在庫から定価で買い戻せる。通常の定番補充やランダム報酬へは加えない。船アイコンは既存のロングシップを共用する。

## 7. 専用海図・報酬・統計

海賊王の海図は必要枚数6の一度きりの物語用海図とする。通常の3枚／5枚海図の2枠を消費せず、破片は対応する六人の初回討伐からだけ得る。通常依頼・断片の購入・通常戦闘の海図抽選からは入手しない。

取得済みの破片は人数カウンターだけでなく討伐済み対象IDと対応づける。六人の初回討伐以外で増やさず、1人の戦後処理の再実行を防ぐ。

ユーザー確認済み：海賊王の海図は `voyageStats.chartsCompleted` に加算せず、探奥神話の10件にも含めない。六枚の破片が揃った時点でも、海賊王討伐・船の報酬回収時でも加算しない。海図達成数は通常の3枚／5枚海図の報酬回収だけを対象とし、この物語の進捗は専用記録で表示する。

| 統計 | 計測 |
| --- | --- |
| 撃破した敵兵・損耗した味方兵・戦闘勝敗 | 各戦の既存精算に接続。敵予備隊は実際に投入・撃破された人数だけ計測 |
| 累計収入・累計獲得信仰 | 実際に確定した報酬がある場合だけ加算。船の価格を収入として加算しない |
| 獲得した固有船 | 五列強の六隻は初回獲得で各1隻。売却後も累計を保持 |
| 海図の達成数 | この専用海図は対象外。海図完成・海賊王討伐・報酬回収のいずれでも加算しない |
| 物語の進捗 | 依頼欄に五列強討伐0〜6人、破片0〜6枚、海賊王の発見／討伐を表示 |

通常賞金首の討伐累計へ物語の七人は加算せず、別の物語進捗で表示する。五列強の勝利と海賊王2戦目の勝利には既存の強編成戦闘報酬を適用する。専用の追加賞金・信仰や固定資金報酬は設けない。通常海図の戦闘断片抽選は適用せず、物語の破片・船を独立して一度だけ付与する。

## 8. 画面・物語テキスト

依頼欄の通常海図と同じ領域へ「海賊王の海図」を追加し、現在の対象・取得枚数・場所案内を表示する。通常依頼を隠す固定表示は作らない。未登場の海賊王の座標をマップやツールチップから先に漏らさない。

噂では名前・人物の特色・船影を伝え、討伐対象の座標を案内する。最初の噂では五列強という呼称と六人の存在を併記し、誤記に見えないようにする。なぜ五列強なのかという追加の設定は未確定とする。

### 噂本文

- ビョルン：「海賊五列強と呼ばれる六人の船長を知っているか。豪勇のビョルンの斧は、船縁ごと敵を割るという。長い船影が、沖に現れたそうだ。」
- エイリク：「赤毛のエイリクの帆を見た者がいる。近づく船には矢が雨のように降り、逃げる船にもその赤い髪が見えるという。」
- イーヴァル：「骨無しのイーヴァルは、自ら槍を振るうより先に、敵の退路を塞ぐそうだ。荷船のような船腹に、幾重もの槍が隠れている。」
- ラグナル：「強襲のラグナルが潮を待っている。大きな船が横付けしたときには、もう甲板にその兵が立っているという。」
- シーヴァルド：「蛇の目のシーヴァルドの船を見た、と船乗りが声を潜めた。逃げ道を探すほど、その目に見透かされるらしい。」
- トルケル：「巨躯のトルケルが動いた。盾と槍を連ねた船団の奥に、ひときわ高い影がある。あの男が守るものを知って、戻った者はいない。」

各噂の末尾にシステムから座標と場所案内を添える。討伐後の通知は「海賊王の海図の破片を得た」と取得枚数を示す。最後の破片では海図完成と海賊王発見を続けて知らせる。

### 海没神話の短い紹介文

海賊王の帆影が途絶え、勝者を語る声も潮に消えた航海が、海の深みに残る。

### 海没神話のエンディング本文

海賊王の旗が最後に見えた日、沖には重い雲が垂れ、岸へ届く波は夜まで荒れていた。あなたの船がその海へ向かったことを、港の人々は覚えている。けれど、帰ってきた船乗りの話はどれも違った。王の帆が裂けたと言う者も、潮語りの灯が消えたと言う者もいた。確かなのは、あの王の船影が二度と港を脅かさなかったことだけだった。波間に残された海図には、もう誰の名も読めない。勝ったのは誰か、沈んだのは何か。海は答えを返さず、ただ静かな航路を岸へ残した。人々はその沈黙を海没の神話と呼び、霧の向こうに灯を見るたび、語られなかった最後の航海を思い出す。

本文には名声・必要兵数・破片数などの具体的条件を記載しない。物語上の沈黙や船影の消失を、プレイヤーの船・兵・資産の消去へ適用しない。閲覧・統計スナップショット・続行・シード指定の再出発は既存の最終航海の操作を共用する。

## 9. 保存と実装の分担

専用領域 `state.pirateKingStory` に版・討伐済みID・噂抽選季節・配置待ち対象と噂の発生拠点・出現位置・固定敵編成・海賊王連戦の現在段階・討伐完了を保存する。破片数と取得済み報酬は討伐済みID／完了状態から求め、別のカウンターと二重管理しない。通常海図や通常賞金首の補充処理へ専用状態を混ぜない。

進行段階は「噂待ち → 五列強出現中 → 次の噂待ち」を六人分繰り返し、「海図完成／海賊王配置待ち → 海賊王出現中 → 討伐完了」となる。連戦段階は海賊王出現中の内部状態として管理する。

- 旧セーブには未開始状態を補完する。過去の通常海賊・賞金首討伐から物語を進めない。
- 討伐済みIDは固定順の連続した範囲だけを採用し、破片数をその結果から求める。未知ID・不正座標・不正人数・矛盾した進行を検証する。
- 準備中の対象は対象ID・連戦段階・専用戦闘種別で識別する。通常の海賊戦・賞金首戦・前線大会戦の結果へ取り違えない。
- 討伐、破片、船、統計、次の進行段階、神話解放を同じ結果確定処理で更新する。報酬成立印を先に検査し、結果の再表示・再読み込みで重複させない。
- 保存失敗時は未保存の通知と再保存手段を用意する。先に保存した戦闘結果と未保存の報酬を別々にして、報酬だけ消える状態を避ける。
- 新規開始では物語進行・目標・破片・報酬成立印を他の航海データとともに初期化する。

責務を分けるモジュール：

| 場所 | 責務 |
| --- | --- |
| `src/pirates/pirateKingConfig.js` | 噂の確率（初期値10%）・距離、固定順、人数配分・敵レベル、専用船ID、噂本文 |
| `src/pirates/pirateKingStory.js` | 状態補完、進行条件、討伐・報酬確定、連戦段階 |
| `src/pirates/pirateKingWorld.js` | 入場時の噂抽選、配置、目標予約、世界への復元 |
| `src/pirates/pirateKingUI.js` | 依頼欄、現地の討伐操作、連戦準備への接続 |
| `src/pirates/pirateKingMapArt.js` | 五列強の旗・海賊王の冠をマップへ描画 |
| 既存の船団・戦闘・最終航海モジュール | 固有船／新船種、味方HP効果、専用結果コールバック、海没神話の解放 |

`actions.js`・`ui.js` には入口と結果の接続を置き、物語全体の条件・固定編成・保存処理を集中させない。HP効果は比較表示・図鑑・戦闘の実値で同じ集計元を参照する。

## 10. 実装時の検証項目

- 名声1,000では噂が出ず、1,001では対象になる。村・街・無法港のみ、実入場で判定する。
- 同じ拠点・季節の不発と当選を保存し、通常海図の枠や噂に影響しない。
- 噂の確率を設定値だけで変更でき、変更後の抽選に反映されること。実施済みの抽選・出現状態は変えない。
- 六人の出現順が固定で、出現中は次が出ない。敗北・引き分け・季節経過で対象や破片が消えない。
- 配置候補がない場合に当選と海図完成を保持し、中央が陸でも海賊王を海へ置く。
- 五列強は各200人・指定した主力兵種・海賊兵のみ。キング1戦目200人、2戦目は前衛200・予備100を保持する。
- 1戦目の戦後損耗を2戦目の編成へ反映し、敗北後は1戦目から再挑戦できる。保存復帰では結果精算を重複させない。
- 通常の前線スコアや国力を動かさず、大会戦の既存予備隊ルールを守る。
- 各破片と各報酬船を初回勝利だけ付与し、1戦目だけの勝利で海没神話を解放しない。
- ヴァイキングシップの味方HP効果が前衛・援軍に1回適用され、敵・攻撃力・防御力に波及しない。
- 専用海図の完成・海賊王討伐・報酬回収で海図達成数を増やさず、通常海図9件と専用海図の討伐完了では探奥神話を解放しない。通常海図の10件目の報酬回収で解放する。
- 海没神話の永久解放、他神話との併存、本文200〜300文字、旅の続行・新規開始を確認する。

## 11. 質問・懸念点と追加案

今回確認済みの事項：

1. 噂は「拠点ごとに季節初回・10%」。後から確率を変更できる設定値として管理する。独立抽選で配置可能な場合、平均10回で一人、六人分で約60回の有効な入場抽選が必要となる。一定回数不発後の保証は採用していない。
2. 五列強の固有船は討伐報酬で各1隻を確実に入手し、指定容量は通常船への追加値とする。
3. 海賊王の海図は海図達成数・探奥神話に含めず、専用の物語進捗として記録する。

未指定だった価格・敵レベル・HP効果上限には本書の初期値を採用した。戦闘・取引は既存規則を共用し、引き分け・逃走・連戦離脱は1戦目へ戻す。

戦闘面では200人戦が続いた後に300人大会戦となるため、兵数だけでなくレベル・甲板の地形補正・時間切れを試走して難度を確認する。物語の進行を失わせず、兵の損耗は通常どおり残すことで、準備不足の挑戦を無償化しない。

海図の進捗欄から六人の船長名と発見・討伐状況を読み返せる。固有の後日談は今後の追加案として残す。

## 12. 検証結果

専用テストと既存の戦果・保存・船取引・最終航海テストで、固定順、抽選境界、設定変更、配置待ち、再挑戦、報酬の重複防止、HP効果と専用海図の統計除外を確認した。ブラウザでは五列強の討伐画面、王の1戦目勝利後の2戦目準備、再読み込み、2戦目敗北後の1戦目への復帰、海没神話の本文・統計、シード指定の再出発画面と取消・続行を確認した。

戦闘難度の調整は実プレイで継続する。画面確認では通常戦の時間切れも確認しており、勝利・敗北の精算経路は確認用の戦闘終了操作も用いて検証した。
