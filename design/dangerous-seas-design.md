# 危険海域 設計書

作成日: 2026-10-04  
更新日: 2026-10-05  
状態: 第1段階・第2段階とも実装・自動テスト済み。第1段階は画面確認済み、第2段階のブラウザ確認は利用上限による承認審査の実行拒否で未実施。ユーザー確定条件と調整値を整理し、検証状況を併記する。

本書は南西・南東の危険海域を扱う。通常の釣りは [釣り詳細](fishing-design.md)、自然探索・海図は [探索・海図・艤装](expansion-design.md)、通常賞金首は [援軍・賞金首](bounty-system-design.md)、通常船種は [船種・造船所](shipyard-design.md) を参照する。危険海域だけの例外を本書に集約する。

## 1. 目的・確定事項・対象範囲

危険海域は、釣果・財宝・強敵を求めて準備して遠征し、成果と滞在リスクを見ながら引き際を選ぶ任意コンテンツとする。最南西と最南東に異なる雰囲気を持たせ、外縁の無法港を補給拠点として利用できるようにする。

### 1.1 ユーザー確定事項

| 項目 | 確定条件 |
| --- | --- |
| 配置 | 最南西・最南東に危険海域を設ける。外縁と核心を分け、既存無法港は外縁の遠征拠点として扱う |
| 区域の形状 | 無法港を基準とする半径6の円形。港位置がずれる場合も、角側5×5の核心候補をすべて円内に保つよう中心を補正する |
| 地形 | 危険海域も海として扱う。専用地形IDによって海判定を壊さない |
| 釣りの生息条件 | 危険海域では通常の4海域・季節・水深の制限をすべて無視する |
| 釣りの餌 | 相性・所持条件・消費を維持する。餌が合わない魚は出現しない |
| 釣りの優遇 | 希少魚と図鑑未登録魚が釣れやすいようにする |
| 日次の危険 | 一日単位で判定し、結果を保存してから行動の区切りで処理する。釣りの各投では判定しない |
| 長期滞在 | 海域ごとの警戒度と荒波を採用する。警戒度は滞在で増え、短い出入りではリセットしない |
| 荒波の周期 | 各海域で12～18日間隔。警戒度や斥候数から天候を変えず、海域外でも絶対日で進める |
| 斥候の航海支援 | 既存の斥候実効値を使い、早期予報・安全航路の発見・日次敵襲の軽減と察知に反映する |
| 荒波対策 | 木材1と繊維1の両方を固定で消費すると釣果を守れる。数量は船数・兵数・釣果数で増やさない |
| 荒波の損失 | 対策しない場合は所持釣果の一部を失う。図鑑登録・最大サイズの記録は残す |
| 自然探索 | 各危険海域に新しい漂流物・難破船の枠を作る。通常の枠は維持し、新規の通常地点は危険海域に生成しない |
| 難破船の選択 | 甲板の探索1日後、引き上げる／積荷の追加探索1日／救助の追加探索1日を排他で選ぶ |
| 限定イベント | 嵐の置き土産・霧中の灯火・巨大魚の回遊・沈みかけた宝船・海底からの鐘を追加する。各海域で置き土産1件＋他のイベント1件を独立管理する |
| 成果と危険 | 獲得した魚・財宝の量から警戒度・荒波・敵襲の危険を追加しない |
| 通常の強敵 | 名声に対応する人数と0.5～1.5の倍率範囲を維持し、1.5に近い倍率を選びやすくする |
| 追加賞金首 | 9種類を追加。各危険海域に最大2人、既存の通常10人とは別枠とする |
| 追加固有船 | 通常の造船所で買える9船種に各1種類。漁船・物語専用のヴァイキングシップは対象外 |
| 固有船の容量 | 基礎船種の兵員上限・物資上限へ、それぞれ10を加算する |
| 賞金首の調整 | 兵数・賞金は通常より多めとし、既存の構成を踏まえて設定する |

### 1.2 初期調整案の位置付け

第2.1節の半径6・中心補正はユーザー確定事項とする。核心までの距離、確率、警戒度の数値、希少魚の一覧、探索枠数、賞金首の名前・編成・賞金は本書の初期調整案とする。ユーザーが個別に指定した数値とは区別し、設定として管理してプレイ検証で調整する。初期実装では本書の初期調整案を採用している。

第1段階は区域表示、釣り優遇、警戒度、敵襲、荒波、海域専用の自然探索、9種類の賞金首・固有船を実装した。第2段階で荒波を周期制へ変更し、斥候の航海支援、難破船の追加探索と救助、5種類の限定イベントを追加した。既存の286魚種、希少魚の定義・抽選比率、通常強敵と専用賞金首の編成・報酬は維持する。移動する巡回船団や長編の連続物語は引き続き追加候補とする。

## 2. 区域・無法港・地図

### 2.1 区域の形状と中心

以下は内部の0始まり座標。画面の座標は各値に1を加える。

| 海域ID | 名称・雰囲気 | 標準中心 | 標準中心での円の最大範囲 | 核心の候補範囲 |
| --- | --- | --- | --- | --- |
| `sw` | 南西・嵐の船墓場。嵐・残骸・海賊船団 | (4,45) | x=0～10、y=39～49 | x=0～4、y=45～49 |
| `se` | 南東・霧の深淵。霧・深海・発光する魚影 | (45,45) | x=39～49、y=39～49 | x=45～49、y=45～49 |

外縁を含む区域は、中心からユークリッド距離6以下の円を地図内へ切り取った形とする。上表の最大範囲を矩形として塗るのではなく、距離二乗36以下のマスだけを選ぶ。

旧10×10の範囲は、港の選択・中心候補の制限・旧配置の移行に使う基準矩形として残す。新しい区域そのものの判定には使わない。

| 海域ID | 移行用の基準矩形 |
| --- | --- |
| `sw` | x=0～9、y=40～49 |
| `se` | x=40～49、y=40～49 |

中心は次の順序で決定し、地形や港を移動させない。

1. 実港は、対応する基準矩形内の無法港から標準中心へのマンハッタン距離が最小の港を選ぶ。同点はyが小さい港、次にxが小さい港を優先する。該当港がなければ標準中心を実港の代わりに使う。
2. 中心候補は基準矩形内の整数座標から選び、角側5×5の四隅がすべて距離二乗36以下に入る候補だけを残す。これにより核心の候補範囲全体を円内に保つ。
3. 実港への距離二乗が最小の候補を中心とする。同点は標準中心への距離二乗が小さい候補、次にy、xが小さい候補を優先する。港位置がずれても半径を広げず、中心だけを補正する。

予報を確認できる遠征拠点は、この実港各1港に限る。該当港がない場合、標準中心は円の計算だけに用い、対応する遠征港があるものとして扱わない。

- 対象は、円形範囲内の既存の海タイル `sea` とする。陸・浅瀬・建物・拠点マスを海に書き換えず、危険判定から除く。この対象地形は初期案であり、将来浅瀬も含める場合は区域条件だけを変更する。
- 母海域は、海・浅瀬を上下左右につないだ最大の海域とする。同面積なら既存の無法港配置と同じく上から左の発見順を優先する。その母海域に属する海タイルだけを候補にし、孤立した内海への配置を避ける。
- 核心は角側5×5の候補範囲内で、世界に存在する全街・村・無法港の座標から最小マンハッタン距離5以上の条件を満たすマスとする。プレイヤーの所属・手配・入港制限で対象拠点を変更しない。距離は上下左右の移動回数の下限であり、陸を横断する海路判定には流用しない。
- 核心条件を満たさない区域内マスは外縁とする。核心が少ない、または存在しないシードでも地形や距離条件を変更して補わない。
- マップ生成式には角を海に固定する保証がない。小島の影響で角が陸・浅瀬になるシードにも対応する。

既定シード2025では、南西無法港の表示座標は(5,46)、南東は(46,46)。港そのものは危険判定の対象外とし、現在の配置を移動しない。港の近くは外縁、距離を確保できる角側が核心になる。核心は小さいため、全コンテンツを核心だけに置かない。

既定港・全海の試算では、各円は97マス、港を除く危険判定候補は96マスになる。円の外周入口から港まで上下左右の移動で6～8歩となり、従来矩形の5～10歩より差を縮める。実際の区域は地形・母海域・拠点除外で欠けるため、この歩数をすべてのシードの保証とはしない。

### 2.2 区域の共通判定

区域ID・外縁／核心は、地図・釣り・探索・賞金首・日次処理で同じ判定を使う。魚の通常生息海域IDとは別の用途として扱う。地形は `sea` のままなので、海戦の甲板、兵種の海補正、通常の海上描画を共用できる。

区域の計算はワールド生成・復元後に行い、地形と拠点が変わった際に再計算する。固定のセル属性だけに保存を頼らない。旧セーブも復元済みの地形・港配置から判定する。

### 2.3 地図と通常コンテンツ

- 外縁は海色・波模様、核心は濃い海色と境界で区別する。既存の現在地・選択枠・地点アイコンの意味を維持する。
- マス説明は、賞金首・探索・海図などがある場合も海域名と外縁／核心を表示する。既存の早期returnで説明が欠けないようにする。
- 海域の描画は地形の直後、各地点アイコンの前に置く。拠点や依頼ピンを隠さない。
- 海の色・核心の斜線・釣り条件・警戒の増減・斥候の支援・退避の説明は、「ルール要約」の危険海域ボタンから「困ったとき」の折りたたみ項目へ案内する。地図下や現在地へ仕組みの常設説明を追加しない。
- 初回進入時は海域名と危険の存在を短く知らせ、詳しい仕組みはガイドへ案内する。毎回の進入では同じ説明を繰り返さない。
- 現在地の見出しは海域名と「外縁／核心・警戒N/12」を当面維持する。補足は目前の荒波の残日数、安全な潮筋による被害なし、必要な対策材料、具体的な船団接近に絞る。予報がなければ「荒波の予報なし。」と短く表示する。
- 荒波の表示例は「荒波まであと2日（安全な潮筋あり・被害なし）。」とし、被害のある予報だけ「木材1・繊維1で釣果を守れます。」を添える。対応港では周辺海域名と「港内は安全です。」を示す。察知済みの接近は「船団接近：明日襲撃。港・区域外への到着で回避できます。」のように、目前の出来事と行動を伝える。
- 釣り条件、海域外で連続3日目からの警戒回復、実効斥候数、予報の察知日数、日次襲撃の軽減率、退避の移動回数・余裕、再襲撃休止の残日数は現場へ常設しない。退避は地図の位置と荒波までの日数を見て判断する。到着日の判定で安全地点に着けば、その日の荒波を回避する。
- 第2.1節で選ぶ対応遠征港では、その海域の既知予報を確認できる。他の街・村・無法港へ南西・南東の予報を割り当てない。街・村・無法港のマスは危険海域の日次判定の対象外とする。
- 新規の通常神託・討伐依頼・通常海図の噂／完成地点は危険海域を避ける。危険海域へ向かう専用依頼は、危険を明記した別の追加候補とする。
- 既存の依頼・海図・通常賞金首の地点は移動・削除しない。危険海域内に残る場合は、地点自体の条件と海域由来の危険を分けて表示する。

## 3. 釣り

### 3.1 候補と既存操作

危険海域では、選択した餌の重みが正の魚種を全魚種から集める。`regions`・`seasons`・`depth` は候補除外に使わない。浅瀬専用の85種も、その餌が合えば海タイルで釣れる。

餌の所持条件・一投ごとの消費・漁船による餌節約、1日最大5投、竿の入力猶予、サイズ抽選、成功判定、売却・加工、図鑑登録と完成率報酬は既存処理を共用する。危険海域だけの操作難度や売価倍率は追加しない。

通常の釣りでは、生息海域・季節・水深・餌の全条件を維持する。魚種の通常生息条件そのものを書き換えず、危険海域専用の抽選分岐を設ける。

### 3.3 抽選枠の初期案

まず次の枠を一度選び、その枠内で既存の餌重みによる抽選を行う。南西・南東は同じ比率から開始し、核心は滞在リスク・探索報酬で差を付ける。

| 枠 | 確率 | 対象 |
| --- | ---: | --- |
| 希少魚 | 20% | 餌が合う希少魚 |
| 未登録魚 | 25% | 餌が合い、図鑑の登録回数が0の魚 |
| 通常 | 55% | 餌が合う全魚種。希少魚・未登録魚も含む |

- 未登録は `codex[id].count > 0` の反対で判定する。在庫 `counts` は売却・加工で減るので参照しない。
- 一投ごとにその時点の図鑑から未登録候補を作る。釣り上げ成功直後から次の抽選へ反映する。
- 希少枠・未登録枠が空なら、その枠の確率を通常枠へ振り替える。全魚種登録後も釣りを継続できる。
- 同じ魚が複数枠の候補に含まれることを許す。ただし別の優遇倍率を重ねない。
- 全候補が空なら既存と同じ空振りとする。正の餌重みがない魚を救済抽選で出さない。
- 抽選済みの魚・タイミング状態は既存の保存／再開方針に従う。画面の再表示で魚を選び直さない。

図鑑では通常の生息条件を維持し、「危険海域では海域・季節・水深を問わず現れる。餌の相性は必要」と説明する。魚名・有効餌などの未発見情報を先に公開しない。

第2段階でも、この常設比率と希少魚一覧、南西・南東の常設条件は維持する。「巨大魚の回遊」の活動期間だけ、既存の大型魚候補から固定した3種の餌重みを2倍にする限定効果を許す。希少20%・未登録25%・通常55%の枠選択、相性0の除外、魚価、サイズ抽選は変更せず、効果終了後は共通抽選へ戻す。

この比率で未登録枠が通常枠と同じ、または空になる場合、現データの期待売値は餌により約63～101資金／匹。5投全成功・既存売値報酬1.2倍なら約378～604資金／日になる。これは餌代・移動・失敗・危険損失を含まない試算であり、実際の未登録候補による値は別に検証する。

## 4. 警戒度と日次の危険

### 4.1 警戒度の初期案

警戒度は海域ごとに0～12で保存する。犯罪の手配度、名声、通常遭遇の移動メーターとは別に管理する。

| 一日を使った行動 | 外縁 | 核心 |
| --- | ---: | ---: |
| 移動 | ＋1 | ＋2 |
| 釣り・待機・自然探索・海図探索 | ＋2 | ＋3 |

- 同じ海域での移動はリセットにならない。釣りを途中で終えても、その日の加算は取り消さない。
- 外縁・核心の判定にはその日の活動位置を用いる。移動は到着先で判定し、到着先が港・区域外なら海域外の日として扱う。
- 海域外で連続3日を過ごした日から、一日ごとに2下げる。1～2日の退出や日数を使わない港の出入りでは下がらない。
- 港での日数消費は海域外として扱う。別の危険海域に滞在中も、離れている側の回復日を数える。
- 戦闘勝利・逃走・再読み込みで全リセットしない。上限12を超えて敵が際限なく強くなることもない。
- 同じ絶対日の再処理では加算・減算を繰り返さない。日次情報の再表示も状態を変更しない。
- 投獄中、陸上、港内は日次敵襲の対象外。日数経過は海域外の警戒回復へ反映し、海域の天候周期は継続する。

### 4.2 日次敵襲の初期調整値

その日の警戒度更新後、以下の基礎率に斥候による相対軽減を掛け、日次敵襲を一回だけ抽選する。荒波は第5章の固定周期で判定し、日次の予兆抽選から分離する。

| 警戒度 | 日次敵襲の基礎率 |
| --- | ---: |
| 0～2 | 5% |
| 3～5 | 10% |
| 6～8 | 18% |
| 9～12 | 25% |

釣りの一投ごと、図鑑の閲覧、魚の加工、同日の再開では判定しない。移動・待機・探索・釣りで日を進めた場合に共通で適用する。現場では現在の警戒値と、察知済みの具体的な船団接近を知らせる。警戒の増減や日次襲撃の休止条件はガイド・READMEで説明する。

敵襲はその日の活動位置・警戒度から編成を一度確定して保存する。敵襲の有無、斥候の察知、回避の成否を表示・再読み込み・雇用後に引き直さない。警戒度は退避しても即座には下がらない。魚・財宝の取得量は抽選率や警戒加算へ使わない。

予兆は未来の予定情報であり、次の日数行動を禁止する未解決イベントには数えない。予定日の日数行動を適用した後、対象海域にいる場合だけ、その行動由来の実イベントへ昇格させる。予定日を含めて一日ずつ処理し、同じ予兆を繰り返し昇格させない。

日次敵襲を解決した日をDとし、D+1～D+3は日次敵襲を発生させない。D+4から通常判定へ戻す。勝利・敗北・引き分け・逃走・降伏のいずれでも適用し、船団共通の絶対日として保存する。別の危険海域へ移動しても短縮しない。探索や賞金首の固定戦闘はこの休止期間の開始・延長に使わない。

### 4.3 一日に重なる戦闘の制御

危険海域では、既存の強制追跡・検問・地点固有の戦闘を優先する。自然探索の固定敵や専用賞金首との戦闘がある日は、日次の追加敵襲を重ねない。通常の移動遭遇・移動イベント・災い襲撃も同じ優先制御へ接続し、危険海域で遭遇を独立に積み重ねない。

荒波が発生する日は新しい危険抽選をしない。地点固有戦闘と荒波が重なった場合は、戦闘の結果処理後の区切りで荒波を解決する。災いなど延期可能な既存襲撃は消去せず次の安全な機会へ送る。追跡・検問の回避期限など、既存の必須処理を日次抽選によって無効にしない。

未解決の危険イベントは船団全体で最大1件とする。新しい日数消費行動は、保留イベントを解決してから許可する。複数日を進める処理は一日ずつ進め、危険が保留になった区切りで停止する。完了後に多数の襲撃が連続するキューは作らない。

### 4.4 斥候の実効値・察知と回避

斥候数は `snapshotOutfitting(state).scouts` を共用し、保有兵と艤装の効果を合算した最大10人分とする。見張り台の5人分を含める。予備隊・編成画面の人数を二重加算せず、実兵員の維持費・食料や既存の戦闘前逃走補助は変更しない。

| 斥候実効値 | 荒波の予告 | 荒波の安全航路発見率 | 日次敵襲率の相対軽減 | 敵襲察知率 | 察知後の1日回避成功率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0 | 3日前 | 0% | 0% | 0% | 0% |
| 1～4 | 5日前 | 15% | 10% | 25% | 35% |
| 5～9 | 8日前 | 30% | 20% | 50% | 55% |
| 10 | 10日前 | 40% | 30% | 70% | 70% |

軽減は基礎率からの相対減少であり、25%の敵襲率は実効値10で17.5%になる。敵人数・レベル・固定賞金首の難度には作用しない。

察知した敵襲は、釣りの開始・探索の日数消費前に警告する。「予定の行動を続ける」か「1日かけて回避する」を選ぶ。回避を選んだ場合は1日だけ消費し、予定していた釣りの餌・投数や探索の報酬を先に消費・付与しない。成功は日次敵襲の解決として扱い、失敗は同じ固定敵との通常の戦闘準備へ進み、既存の戦闘・逃走・降伏を選べる。続行時も固定した敵襲は行動の区切りまで保持する。

敵襲察知と回避の結果は遭遇確定時に一度保存する。後の雇用・解雇・艤装変更で再抽選しない。未解決の警告を閉じたり再読み込みしたりして新しい候補を引くことも許さない。

## 5. 荒波

### 5.1 天候周期と早期予報

海域ごとに荒波の発生日を絶対日で保存し、発生日から次の発生日まで12～18日の整数を等確率で選ぶ。警戒度・斥候数・魚や財宝の量で間隔を変えない。新しい世界と周期未設定の保存は現在の世界日時から12～18日後を初回予定日とし、旧形式の確定済み予報日はそのまま引き継ぐ。

海域外・港・別海域でも天候周期は進む。予定日に対象海域外なら被害なしで周期を完了し、帰還時に過去の荒波をまとめて発生させない。退出・再進入・雇用・解雇・再読み込みで予定日や次の間隔を引き直さない。未解決の戦闘があっても天候の日付管理は進め、被害イベントの表示だけを安全な区切りまで保留する。

波本体と敵襲に付随する延期波は、適用時の現在地がその波の対象海域内であることを確認する。旧保存に残る実際の荒波の通知や途中情報も同じ条件で検査し、港・区域外・別の危険海域では対象外の波を棄却する。同じ対象海域内では確定済みの損失内訳・対策結果と保存復帰を維持する。

予告日は第4.4節の斥候実効値から決まり、通知と現在地の説明で残り日数を知らせる。予報通知は現在の危険海域と第2.1節の対応遠征港に限り、対応港では周辺海域の予報であることと港内は安全であることを示す。一般無法港・通常の海・街・村へ他海域の予報を通知しない。対応港でも実際の荒波モーダルと被害は発生しない。一度知った予定日は斥候が減っても失わない。増員で早期察知の条件を満たした場合は既存の予定日を知らせ、新しい周期を抽選しない。予報が出ていても帰港・退避・通常行動を許可する。

周期生成時に安全航路判定用の乱数を一度固定する。予報を認知した時点と認知中の斥候段階に対応する安全航路発見率を、同じ乱数に対して比較する。増員による改善は許すが再抽選せず、一度発見した安全航路は減員しても保持する。安全航路があればその周期の荒波被害を回避し、なければ発生日までの退避か固定資材による対策を選べる。斥候が天候自体を消したり遅らせたりする効果にはしない。

### 5.2 発生日の対策

発生日の移動後、対象海域にいる場合だけ荒波の被害対象とする。港の座標または区域外へ到着していれば回避できる。安全航路未発見のまま活動を続けた場合は、その行動の区切りで次の選択を出す。

| 選択 | 条件・結果 |
| --- | --- |
| 木材1・繊維1で釣果を固定する | 両方を所持しているときに選べる。双方を同時に1ずつ消費し、釣果損失を0にする |
| 一部の釣果を諦める | 資材を消費せず、確定した釣果の損失を適用する |

木材1で魚箱を補強し、繊維1で縛って固定することで魚を守る。

片方だけの消費・代用品・資金による代替は設けない。両方を確認してから同時に消費する。資材不足の選択は無効化し、不足する物資を示す。艤装の「嵐対策用の覆い」は既存の維持費軽減を維持し、今回の対策を無料化しない。

### 5.3 釣果損失の初期調整値

選択画面を開く時点の所持釣果総数をNとし、損失数を `floor(N × 0.05)` とする。魚種ごとに割合を切り捨てず、全在庫から所持個体を等確率・重複なしで選び、魚種別の損失内訳を確定する。価格・希少度・図鑑登録有無による優先は付けない。

- N=0～19なら損失0。最低1尾を強制しない。損失0の場合は資材消費の選択を出さず、被害なしとして解決する。
- 大量の在庫を個体配列へ展開せず、数量を重みとして抽選する。選んだ個体を除いて次を抽選し、在庫数を超えて失わない。
- 警戒度・成果量は荒波の周期や損失率を変更しない。斥候の安全航路回避と資材保護を適用できなかった場合だけ、固定の損失率を使う。
- 減らすのは在庫 `counts` のみ。図鑑登録回数、最大サイズ・場所・日付、図鑑完成率、解放済み報酬、航海統計の累計釣果を巻き戻さない。
- 新たに釣った魚も、選択画面を開く時点で在庫にあれば対象にする。釣り中の操作に割り込まない。
- 行動終了後に損失内訳を確定し、保存成功後に選択画面を表示する。選択・消費結果も保存し、再表示・再読み込み・二重クリックで再抽選や二重消費をしない。
- 選択中は売却・加工・別行動で対象在庫を変更させない。モーダルを閉じて回避できないようにし、解決後に通常操作へ戻す。

結果には使用した資材または失った魚種・数量を示す。魚の腐敗期限や船の個別耐久は追加しない。

## 6. 強敵

名声から求める基礎人数は既存の `pirateEnemyCount` と同じ範囲の中央値を使う。倍率の初期案は次とする。各Uは0以上1未満の独立した一様乱数。

| 区域 | 倍率 | 平均倍率 |
| --- | --- | ---: |
| 外縁 | `0.5 + max(U1, U2)` | 約1.167 |
| 核心 | `0.5 + max(U1, U2, U3)` | 1.25 |

0.5～1.5の範囲を保ち、上側が選ばれやすい分布とする。既存の最低人数と最大200人・20部隊を最後に適用する。低名声でも必ず200人にはせず、高名声で上限へ達した場合も上限を超えない。

危険海域の通常敵襲・専用自然探索の敵は精鋭編成とし、兵種の候補・レベル1～3は既存の精鋭生成を共用する。固定賞金首は後述の固定編成であり、この名声倍率抽選を適用しない。警戒度は敵襲率に作用し、倍率・敵レベルをさらに重ねて増やさない。

通常の戦闘報酬、兵員精算、救護、捕虜、敗北・逃走・降伏の処理を共用する。危険海域の通常敵襲は犯罪にせず、国力・戦況スコア・最寄り貴族の好感度へ通常正規軍戦の効果を流用しない。危険海域の追加報酬は探索と専用賞金首で付与し、滞在による日次敵襲自体に別の追加賞金は設けない。

## 7. 漂流物・難破船

### 7.1 独立枠の初期案

| 項目 | 各危険海域の設定 |
| --- | --- |
| 漂流物 | 最大2件 |
| 難破船 | 最大1件 |
| 初回配置 | 漂流物1件・難破船1件 |
| 日次出現 | 漂流物5%、難破船1/60。各種一日最大1件 |
| 寿命 | 120日 |
| 探索時間 | 漂流物は1日。難破船は甲板1日＋任意の追加探索1日 |
| 戦闘確率 | 外縁は50%・75%、核心は75%・100%から各等確率 |

海域内の非拠点・未使用位置から均等に選ぶ。漂流物・難破船は区域全体へ配置し、核心だけへ集中させない。地点の生成時に区域段階、報酬プロフィール、戦闘確率、寿命を固定する。

通常の自然探索は共通枠5件・難破船2件と現行の出現確率を維持し、新しい候補から危険海域を除く。危険海域の探索枠は通常枠へ合算せず、南西・南東も独立して数える。候補不足なら生成を見送り、無限な再抽選や他海域への代替配置をしない。

### 7.2 報酬の初期案

資金・高級品は外縁で通常の2倍、核心で3倍とする。名声・敵人数・経過日数から報酬を増やさない。

| 地点 | 外縁の資金／高級品合計 | 核心の資金／高級品合計 |
| --- | --- | --- |
| 漂流物 | 900～1100／4～8個 | 1350～1650／6～12個 |
| 難破船 | 1800～2200／8～16個 | 2700～3300／12～24個 |

通常の抽選結果の資金・高級品数量へ倍率を掛け、高級品は既存の2種類への配分を維持する。新規開始する難破船では、この資金・高級品と従来の船20%で1隻・海図断片抽選を甲板の共通報酬とし、兵員の救助は第7.4節の追加選択へ移す。危険海域の固有船はこの船抽選へ入れない。通常探索・漂流物・第1段階の途中保存は元の報酬を維持する。

探索開始時に敵・報酬を一度だけ確定して保存する。勝利・非戦闘時だけ付与し、敗北・逃走・引き分け・降伏ではその段階の報酬なしで探索を終了する。甲板の報酬を回収済みなら、追加探索の非勝利で既に得た分を取り消さない。通常戦闘報酬との併給、船を先に加算した容量再計算、物資・兵員の超過整理は既存の自然探索と同じにする。

### 7.3 配置予約

通常探索、危険海域探索、限定イベント、通常賞金首、危険海域賞金首、海賊王物語、受注中／未受注の依頼、通常海図の未公開完成地点・噂、港移設が同じ予約位置を参照する。追加地点を各機能の予約一覧へ接続し、後から別の地点が同じ座標を使わないようにする。

探索・戦闘中の地点は寿命から保護する。固定済みの危険度・報酬を、場所の段階変更や警戒度変化で選び直さない。

### 7.4 甲板後の選択・追加探索

難破船の甲板を1日かけて探索し、既存の危険度による固定敵がいれば先に解決する。甲板の共通報酬を確定付与した後、引き上げる・積荷を探す・救助するのいずれか一つを選ぶ。追加探索を両方実行したり、同じ追加探索を繰り返したりできない。

| 選択 | 所要日数 | 第2段階の初期調整値 |
| --- | ---: | --- |
| 引き上げる | 追加0日 | 甲板の報酬を持ち帰り、探索を終了する |
| 船倉の積荷を探す | 追加1日 | 甲板の資金・高級品の50%を追加。核心の合計上限は資金4950・高級品36個 |
| 生存者を救助する | 追加1日 | 兵種は従来の候補から3～5人、Lv2または3。25%で兵員に代わり通常海図断片1個の手掛かりを得る |

追加の戦闘・事故は次の初期調整値を使う。斥候実効値0／1～4／5～9／10で、追加戦闘率・事故率からそれぞれ0／5／10／15パーセントポイントを引く。追加戦闘率は最低5%とする。第4.4節の日次敵襲率軽減とは別の判定であり、重ね掛けしない。

| 区域 | 積荷の追加戦闘率 | 救助の追加戦闘率 | 各追加探索の事故率 |
| --- | ---: | ---: | ---: |
| 外縁 | 25% | 15% | 35% |
| 核心 | 35% | 25% | 50% |

積荷の追加量は資金・各高級品を個別に半分へ切り捨てる。事故時は追加分の各数量の25%を切り捨てて差し引き、甲板で回収済みの分は減らさない。救助の事故は所持範囲で木材1・食料2まで失い、兵員損耗は起こさない。成果量で戦闘率・事故率を増やさない。

開始時に甲板と両追加選択の敵・報酬・事故・斥候実効値を固定して保存する。甲板終了時や追加探索の区切りで荒波・日次敵襲が保留になっていれば先に解決し、その後に同じ探索段階へ戻す。日数適用済み印・選択済みの枝・付与済み報酬を保持し、再開で日数を重ねたり別の枝を選び直したりしない。追加探索または引き上げが完了するまで、元の難破船位置の予約と期限保護を維持する。

### 7.5 5種類の限定イベント

通常探索・賞金首と独立した活動枠を各海域に設ける。嵐の置き土産専用枠1件と、他4種が共有する通常イベント枠1件は独立し、同じ海域で最大2件が共存できる。現地の選択・戦闘・途中保留・報酬確認まで対応する枠を占有し、終了または未着手の期限切れ後にその枠だけを空ける。途中活動は船団全体で1件を維持する。斥候0でも現地で参加できる。両枠とも全配置の予約を避け、同じ位置に重ねず、港・陸・浅瀬へ代替配置しない。

通常イベント枠が空いている日の日次出現率は5%を初期調整値とし、置き土産の有無にかかわらず適合する種類から均等に選ぶ。南西は灯火・回遊・宝船の3種（各約1.67%）、南東は鐘を加えた4種（各1.25%）。置き土産は新しい荒波後、専用枠と候補位置が空いていれば生成する。専用枠が埋まっている波では追加・上書き・待ち行列を作らず、枠が空いた後も同じ荒波を再処理して増やさない。種類・座標・灯火の正体・回遊魚3種・報酬・敵・事故用乱数・期限を出現時に固定する。表示や未選択画面の開き直しで内容を再抽選しない。

期限は、同じ側の外縁無法港から地点までの最短移動回数＋活動日数＋余裕10日とする。移動は現行の上下左右・全地形移動可に合わせる。活動日数は鐘3日、他1日を初期値とし、候補港がなければ生成を見送る。開始済みの選択・戦闘・報酬確認中は期限から保護する。

## 8. 9種類の賞金首

### 8.1 出現・補充

- 危険海域専用9テンプレートを定義する。通常の27テンプレート・活動10人の抽選へ混ぜない。
- 各海域に最大2人、全体で最大4人。同じテンプレートは両海域を通じて同時に1人まで。
- 初回に各海域を補充し、討伐・寿命終了による欠員は次の季節初日に補充する。寿命は通常と同じ600日を初期案とする。
- 南西専用4種・南東専用4種・両海域共通1種とする。適合する未討伐種類を優先し、全種類を討伐済みなら再登場を許す。討伐済み種類の履歴は表示履歴の上限とは別に保存する。
- 核心に空きがあれば核心へ、なければ外縁へ配置する。候補不足なら空き枠を残し、次の補充で再試行する。
- 到着だけでは戦闘にしない。名前・編成・人数・賞金・固有船を確認して任意に討伐する。
- 出現時に名前・編成・賞金・位置・船を固定する。敗北・逃走・引き分けでは残留し、再挑戦時は敵全快。交戦中の寿命消滅を防ぐ。

### 8.3 精算・勢力関係

勝利時は通常勝利報酬に表の賞金と対応固有船1隻を追加する。討伐自体は犯罪にしない。通常賞金首と同じく黒ひげ好感度−3、他勢力の貴族＋1を一度だけ適用し、通常の海賊撃破に伴う関係変化を重ねない。国力・拠点支持度・戦況は変更しない。

同勢力の名誉家臣は討伐できない既存ルールを維持するため、海賊勢力の名誉家臣はこの9種類を討伐できない。一覧・地図・詳細の閲覧は可能とする。開始前の所属変更も再確認する。

賞金首討伐累計、戦闘勝敗、敵撃破数、恒久損耗、収入、固有船獲得統計へ通常の確定経路で記録する。海賊王の破片・進行・専用船と通常海図の完成件数は変更しない。通常の戦闘由来の海図断片抽選は既存条件で行う。

## 10. 行動・危険イベント・保存の順序

現在の釣り・探索は、日数適用直後に保存する。日次処理から直接通常の戦闘準備に移ると保存禁止に当たり、行動と日付が巻き戻る。危険結果の記録と戦闘開始を分離してこの衝突を防ぐ。

1. 釣り・探索前に斥候が日次敵襲を察知した場合、固定した警告と続行／1日回避の選択を保存して提示する。選択するまで元の行動の日数・餌・報酬を適用しない。続行またはその他の行動開始時に、対象・所要日数・探索固有の敵／報酬・追加選択の全結果を確定し、日数適用前の記録を保存する。
2. 日付、食料、維持費、通常世界と危険海域の地点更新を一日ずつ進める。危険海域の日次処理は警戒度と危険結果を専用の保留領域へ記録し、ここでは `pendingEncounter` を上書きしない。
3. 行動の日数適用済み印、処理済み絶対日、危険結果、確定編成・天候周期・既知予報・安全航路判定をまとめて保存する。保存失敗なら状態・世界・消費を適用前へ戻し、処理を進めない。
4. 釣りの投と結果、探索の敵・報酬など、その行動の処理を進める。地点固有敵がある場合は追加敵襲を生成しない。行動中は保留敵襲を開かず、一投の操作へ割り込まない。
5. 釣り終了、5投の結果確認終了、探索の各段階／戦後処理終了、限定イベントの各段階、移動・待機終了を区切りとし、その行動由来の保留危険を解決待ちへ移す。甲板から追加探索へ進む前、追加探索や鐘の次段階へ進む前にも保留危険を先に解決する。釣りパネルを閉じて別の行動へ移る場合は、残り投の終了を明示して元セッションを終了し、保留危険を先に解決する。
6. 他の戦闘・探索・海図・選択イベント・結果画面がないことを確認し、保留危険を選択画面または戦闘準備へ渡す。通常の画面同期は確定結果の表示だけを行い、抽選しない。
7. 勝敗・逃走・降伏、察知後の回避、荒波の選択を一度だけ精算し、日次敵襲の3日休止と解決済みを保存する。元の探索・限定イベントが保留なら同じ段階へ戻し、全て完了した後に通常操作へ戻す。途中保存からは同じ保留を再開する。

危険敵襲・危険賞金首の確定済み準備も、固定編成の賞金首と同様に保存可能にする。戦闘進行そのものの途中保存は既存方針を維持する。戦闘後の対象確認・報酬・関係変化・統計・保留消去は一つの結果IDで二重適用を防ぐ。

保留危険には発生元の行動ID・判定日・処理段階（事前警告／続行後の予定／行動中／解決待ち／表示・戦闘中）を保存する。続行後の予定敵襲は翌日の日数行動が終わった区切りで発生へ移す。釣りの再開時に保留を確認しても、同日の日数適用済みセッションが行動中なら残り投を先に再開する。探索・限定イベントの再開では付与済み報酬と日数適用済み段階を戻さない。再読み込みだけで敵襲・荒波を前倒ししない。

新しい日数行動を禁止するのは、進行中の元行動または解決待ち以降の実イベントがある場合とする。未来日の荒波予兆と続行を選んだ予定敵襲は次の日数行動を許可する。釣りセッションを閉じたことで危険だけ消えることもない。通常の災い襲撃にも釣り／危険保留の延期条件を接続する。

敵襲の1日回避中に荒波予定日を迎えた場合も、天候だけ進めて被害判定を消さない。同日の固定した荒波を延期情報として保持し、敵襲の回避・戦闘を解決した後に一件だけ表示する。解決順のために発生日・安全航路・損失対象を再抽選しない。

### 11.2 旧セーブの移行

- 新領域がない保存には、警戒度0・専用未生成状態を補完する。地図・拠点・既存地点の復元後に区域を計算する。
- 第1段階の保存には周期・斥候察知・限定イベントの新領域を補完する。確定済みの旧荒波予報日は維持し、予報未設定の海域だけ世界の現在絶対日から初回周期を生成する。移行や再読み込みで既存危険の成否を引き直さない。
- 限定イベント版1の `active` にある置き土産は、版2の専用枠 `stormAftermath` へ移す。ID・位置・期限・固定乱数・報酬・進行と途中参照を保持し、日数消費・支給を繰り返さない。他4種は通常枠に保持する。両枠は配置予約・円形化の移設・発見表示を共有する。
- 旧保存の荒波本体・敵襲に付随する延期波・実際の荒波の通知は現在地と対象海域を照合し、対象海域外の波を棄却する。予報通知は現在海域または対応遠征港に限る。別の危険海域へ同じ被害を流用しない。
- 円形化の移行は復元時だけ行う。新区域外の未着手の専用探索・専用賞金首・限定イベントを同じ海域へ決定的に移し、元と同じ外縁／核心、元座標への距離二乗、y、xの順に候補を優先する。処理順は南西、南東、各海域の探索、賞金首、限定イベント、各種別の地点ID昇順とする。候補不足なら同海域の別段階を許すが、地点ID・元の段階・報酬プロフィール・危険度・固定報酬・敵編成・期限は変更しない。
- 途中探索、開始済みまたは進行履歴のある限定イベント、専用戦闘の地点、保留危険がある時の現在地は移動から保護し、元の座標と途中結果を保持する。通常の地点と全配置の予約を避けて移す。
- 候補不足 `unplaced` と円外の保護待ち `deferred` は区別し、どちらもない時だけ `placementVersion=1` を保存する。候補不足・保護待ちがある間は地点を削除せず、元の座標・期限と移行版0を保持する。既に移した地点も保存し、次の復元時に残った対象だけを再試行する。敗北・逃走などで賞金首が残る場合も、保護解除後の次の復元で移設できる。
- 移行版1の保存後は、再読み込みや日次更新・補充で再移設しない。
- 通常探索、通常賞金首、海賊王物語、依頼、海図、無法港、図鑑、既存の船は移動・削除・再抽選しない。
- 危険海域内に残る旧通常探索は、通常の報酬プロフィールのまま扱う。場所だけで2倍・3倍に変更せず、専用枠にも数えない。消滅／回収後、新規の通常地点は区域内に生成しない。
- 専用地点と専用賞金首は全予約位置を避けて初回生成し、その印を保存する。再読み込みだけでは補充しない。
- 既存の途中行動・固定報酬・敵編成を保ち、移行時に追加の危険を遡及して抽選しない。
- 第1段階の途中難破船は従来の1日探索・固定救助兵員を維持する。新しい甲板／追加探索への分割は新規に開始した専用難破船だけに適用する。
- 既存の探索検証には資金1100以下などの通常報酬前提がある。専用探索はプロフィールと生成版に対応した検証を用い、3300までの資金や増加した高級品を有効に復元する。
- 設定を調整しても、過去の有効な版で保存した途中報酬を減額・再抽選・破棄しない。安全な整数と対応プロフィールを検査し、過去の版も復元できるようにする。
- 追加積荷と限定イベントは通常探索の資金1100・専用甲板3300の検証上限へ流用せず、段階と報酬プロフィールに対応した検証を行う。甲板と追加積荷を合計した核心資金4950・高級品36個も有効な結果として保持する。
- 図鑑報酬の解放履歴を維持する。荒波で魚在庫が減っても報酬を閉じない。今回の初回範囲では魚種数を増やさない。

## 12. 実装時の責務分割
