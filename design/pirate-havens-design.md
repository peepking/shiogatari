# 無法港・海賊勢力 追加設計書

状態：実装済み。2026-09-21更新。
「暫定」はプレイを通じて調整する初期値を示す。調整値は主に `pirateConfig.js` で管理する。Lv4～5中心の精鋭と街を出る際の呼び止めイベントは今回の対象外。

## 目的

外洋を神託・海図だけの目的地にせず、無法港への寄港、海賊依頼、禁制品取引、海賊系部隊の雇用を通じて、継続的に航行する理由を作る。

無法港は「外洋海賊」という一枚岩の国家ではなく、複数のならず者・略奪者・賞金稼ぎ・密輸商が集まる、統治勢力の外にある港とする。プレイヤーは無法港と取引・協力できるが、その行動は既存勢力との関係に影響する。

## 基本方針

- マップ全体に無法港を約10拠点配置する。
- 無法港は通常の街に相当する行動を提供する。物資取引、部隊雇用、海賊依頼受注、造船所、神託の達成報告を利用できる。潮盟拠点の訪問・建設・支援は対象外。
- 無法港は海図地点、自然探索地点、討伐地点および既存の村・街と競合しない座標に配置する。
- 無法港ごとの特色や固有システムは、初回実装では追加しない。
- 既存の「外洋海賊」勢力IDを利用し、無法港との好感度は全拠点で共有する一つの値とする。
- 名声は善行だけを表す値ではなく、悪名を含む航海者としての知名度・力量と解釈する。海賊行為でも名声は通常どおり上昇する。
- 船で到達可能な座標へ配置し、外洋の一か所に偏らないよう地域を分散する。未公開の海図地点も重複判定に含め、後から生成される探索・依頼地点も無法港を避ける。
- 無法港は国力、国家間外交、領土戦争・占領の対象外とする。

## 顔役「黒ひげ」

- 既存の貴族に相当する人物として黒ひげを1人登録する。肩書きは「無法港の顔役」。全海賊を統治する君主ではない。
- 内部IDは `pirate_blackbeard`、勢力IDは既存の `pirates` を使用する。
- 黒ひげの好感度を無法港共通の好感度として使用し、別の勢力好感度との二重管理は行わない。
- 一つの無法港を本拠地として固定し、黒ひげと会えるのはその港だけとする。
- 海賊依頼は全無法港で受注でき、黒ひげとの面会を条件にしない。
- 通常貴族用の依頼生成、名誉家臣への勧誘、軍資金提供は適用しない。
- 既存の貴族一覧・人物表示を活用する。黒ひげの肖像は別途用意する。

## 海賊勢力の関係

### 好感度

- 海賊依頼を達成すると、海賊勢力の好感度を上昇させる。
- 上昇量は既存依頼による好感度変動と同程度とする。
- 同じ達成時に、対象の通常拠点1件の支持度と、その担当貴族1人の好感度を同量低下させる。
- 関係の変動は依頼の受注時ではなく、達成時に一度だけ適用する。
- 海賊討伐・賞金首討伐など直接的に敵対する依頼の達成時に海賊好感度を下げる。通常の納品・配達では下げない。通常遭遇のならず者船団・略奪船団を倒すだけでは下げない。
- 関係段階が変わったときは、たとえば「敵対から警戒へ」のようにダイアログで通知する。
- 依頼達成のログと結果画面には、変動した海賊好感度、拠点支持度、貴族好感度を表示する。

### 関係悪化の対象

- 襲撃・密輸：目的地に最も近い通常拠点を選ぶ。密輸の配送先が通常拠点なら、その拠点自身が対象になる。
- 運び屋・物資納品：発注した無法港に最も近い通常拠点を選ぶ。
- 既存のマンハッタン距離で比較する。同距離は拠点ID順で決める。
- 依頼生成時に拠点ID、勢力ID、担当貴族IDを保存し、報告場所や占領によって対象を選び直さない。
- 通常依頼の関係上昇と海賊依頼の関係変化を重ねて適用しない。対象が見つからない不正データでは無関係な勢力へ振り替えない。

### 正規軍の通常遭遇

- 正規軍の通常遭遇は、所属勢力と交戦中の敵勢力が所有する拠点の近傍に限る。基礎人数40人以上という出現条件は使用しない。
- 海賊・貴族好感度による追加の正規軍遭遇は停止する。禁制品の摘発は検問イベントで扱う。
- この正規軍との戦闘に勝敗しても、好感度・支持度は変動させない。
- 通常の街・村における取引、雇用、依頼受注は、海賊との好感度では制限しない。
- 商人救助の敵は海賊とし、商人の所属勢力は救助結果の支持度・好感度に使用する。検問突破など、明示的に正規軍と戦う選択イベントは維持する。
- 名誉家臣である間は、海賊勢力が発注する依頼を受注できない。無法港での取引と部隊雇用は可能とする。
- 海賊依頼を受注済みでも仕官できる。仕官前の依頼は期限内なら継続・達成可能とし、仕官後の新規受注だけを禁止する。

## エンカウントと敵対集団

既存の海賊敵編成を、無法港に属する者を含む単一組織としては扱わない。敵対する船団・集団として表示する。

| 表示名 | 編成 | 役割 |
| --- | --- | --- |
| ならず者船団 | 歩兵・弓兵・斥候・海兵のみ。海賊系6兵種は除外 | 外洋での通常敵および海賊討伐相当の敵。最序盤の難易度を抑える |
| 略奪船団 | 現在の強敵海賊 | 賞金首相当の強敵 |
| 賞金稼ぎ | 新規の海賊系兵種のみで構成 | 懸賞金の対象を見境なく狙う第三者。海賊も標的にする |

- 海賊系ユニットは、通常エンカウント、討伐系の敵編成、賞金稼ぎの編成に混在できる。
- 無法港との取引や雇用は、ならず者船団・略奪船団との敵対を自動的に解消しない。
- 禁制品に関する危険は、正規軍のお尋ね者遭遇ではなく検問イベントへ集約する。

## 禁制品

無法港では通常の原料に加え、高級品枠として禁制品を扱う。

| 禁制品 | 基礎価格 | 無法港の需要 | 通常拠点の需要 |
| --- | ---: | --- | --- |
| 違法薬物 | 100 | 低い | 高い |
| 密造酒 | 100 | 低い | 高い |
| 盗品武具 | 150 | 低い | 高い |
| 盗品工芸品 | 200 | 低い | 高い |

- 禁制品の入手経路は無法港での購入と海賊依頼での積荷受領に限定する。
- 戦闘報酬、自然探索、海図報酬、行商人の商品、神託、通常の調達依頼・配達依頼の抽選には含めない。
- 通常拠点では売却できるが、新規販売在庫として生成・補充しない。プレイヤーから買い取った禁制品を再購入できる在庫へ戻さない。
- 禁制品は通常の物資在庫と同様に扱い、既存配達依頼以上の所持・売却ガードは追加しない。
- 禁制品を所持している、または無法港で禁制品を売買した記録がある場合、検問イベントで摘発され得る。
- 無法港での売買が成立した時点の絶対日を保存する。記録の保持は暫定30日とし、期限経過後は記録のみを理由とする摘発対象から外れる。所持品が残っている場合の摘発判定は継続する。
- 摘発時には戦闘へ移行する派生を追加する。
- 禁制品を売買した記録を用い、通常の街を出る際に呼び止められるイベントを追加する案を検討する。

## 海賊勢力の依頼

海賊依頼は既存の依頼より高いリターンを持つ。関係への悪影響と検問・遭遇リスクが対価となる。

| 依頼 | 内容 | 難易度・報酬 | 関係への影響 |
| --- | --- | --- | --- |
| 隊商襲撃 | 隊商を討伐する | 通常討伐より人数を多めにし、実際の敵規模に応じた報酬 | 達成時に海賊好感度上昇、近隣拠点支持度・近隣貴族好感度低下 |
| 商船団襲撃 | 商船団を討伐する | 強敵討伐より人数を多めにし、実際の敵規模に応じた報酬 | 同上 |
| 密輸 | 無法港以外の拠点へ禁制品を運ぶ | 配達依頼の報酬額の2倍 | 同上。禁制品による検問リスクあり |
| 運び屋 | 他の無法港へ禁制品を運ぶ | 配達依頼の報酬額の2倍 | 同上 |
| 物資納品 | 無法港へ物資を納品する | 内部処理は調達依頼と同等 | 同上 |

- 依頼達成時の支持度・好感度の上下量は、依頼種別によらず一律とする。
- 海賊依頼の失敗に、既存依頼以上の追加デメリットは設けない。
- 名誉家臣は上記の海賊依頼を新規受注できない。仕官前に受注した分は達成できる。
- 襲撃依頼の敵編成は依頼生成時に確定・保存する。受注前に推定人数・編成の種別・報酬を示し、受注後の名声変化や再読込では変えない。
- 人数増加率1.25、依頼資金係数1.5を独立した定数とする。200人上限で切り捨てた仮想人数を報酬計算に含めない。依頼資金は `(実人数×50＋100)×1.5` を四捨五入し、通常の戦闘報酬も別途得る。
- 密輸・運び屋の積荷、期限、目的地表示、納品時の数量確認は既存配達を活用する。没収後も補充して期限内に達成でき、荷物を失った瞬間には自動失敗にしない。
- 討伐完了地点は既存の完了管理を使用し、再戦による報酬・関係変動の重複を防止する。

## 検問イベント

- 通常の検問イベントに、禁制品を発見する判定と摘発戦闘の派生を追加する。
- 禁制品関連の危険は検問イベント側で扱い、海賊好感度による正規軍遭遇とは原因を混同しない。
- 摘発戦闘の敵は近隣勢力の正規軍とする。
- 禁制品検問と既存の通常検問は処理を分ける。通常検問の賄賂50資金・好感度上昇をそのまま流用しない。
- 摘発後は「引き渡す」「賄賂」「強行突破」を提示する。兵員ゼロでは強行突破不可、資金不足では賄賂不可でも、引き渡しは常に選べる。
- 引き渡しでは所持する禁制品を没収する。資金の支払いを必須にしない。積荷は他の禁制品と同様に没収される。
- 記録だけで摘発された場合は「警告を受け入れる」で担当貴族好感度−3、取引記録を解除する。資金・兵員ゼロでも解決できる。

### 賄賂

- 名声と出撃可能な兵員規模が大きいほど成功率が上がり、禁制品所持数が多いほど下がる。
- 兵員規模は編成条件を考慮した出撃可能人数を使い、最大200人。控えを大量に抱えるだけでは有利にしない。
- 成功率は `40%＋min(20%, 名声÷2000)＋min(20%, 出撃可能人数÷1000)−禁制品数×0.5%` を20～80%に制限する。費用は `200＋禁制品数×10` 資金。各係数を定数化する。
- 支払い前に金額と成功見込みを表示する。成否を問わず資金を消費する。
- 成功時は通過できる。通常検問のような貴族好感度上昇は付けない。
- 失敗時は担当貴族の好感度が下がり、同じ検問では賄賂を再選択できない。引き渡し・強行突破へ戻る。
- 検問ID、対象勢力・貴族、支払済み・賄賂失敗などの進行状態を保持し、画面更新による再抽選や二重徴収を防ぐ。

## 名声と敵規模の再設計

### 通常遭遇

1. 既存の名声アンカーを活用して基礎人数を求める。暫定では人数レンジの中央値とする。
2. 選択可能な敵種別を決める。略奪船団・賞金稼ぎは基礎人数が最低人数に達したら解禁する。正規軍は人数ではなく、交戦関係と敵拠点への距離で候補を決める。
3. 基礎人数に50～150%の一様乱数を掛け、整数に丸める。
4. 種別の最低人数～200人に収め、既存の最大20部隊・各10人の配分処理に渡す。

既存レンジから人数を抽選してさらに倍率を掛ける二重抽選は行わない。
敵種別は選択候補ごとに通常／強編成の基礎値を評価する。出現可否と人数生成で別の名声基準を持たない。
遭遇生成時に抽選結果を保存し、祈り・逃走選択や画面の再表示では引き直さない。

| 敵種別 | 最低人数（暫定） | 基礎人数 |
| --- | ---: | --- |
| ならず者船団 | 既存の少人数遭遇を維持 | 通常アンカー |
| 略奪船団 | 30 | 強編成アンカー |
| 賞金稼ぎ | 20 | 強編成アンカー |
| 正規軍 | 40（生成人数の下限のみ。出現条件には使わない） | 強編成アンカー |

- 名声1,000の通常基礎75人なら、約38～113人が抽選範囲になる。
- 高名声では上限200人へ収まる結果が増える。人数上限を超える部隊は作らず、報酬は実際に生成・出撃した人数を基準にする。
- 略奪船団・賞金稼ぎの名声による出現制限は通常遭遇に適用する。依頼・検問の指定戦闘は最低人数を保証し、危険を事前に示す。
- 依頼は受注前に規模を確認できる。検問は無条件に選べる非戦闘の解決策を残す。
- 既存の斥候・海への祈り・逃走処理自体は、この変更では強化しない。

### 精鋭と難易度調整の範囲

現行の通常Lv1、強編成・正規軍Lv1～3では、味方Lv5が揃うと人数の増減だけでは脅威が不足する可能性がある。
低確率のLv4～5中心の精鋭は追加候補とするが、今回の人数変更には混ぜない。出現率・名声条件・報酬・事前表示を別途設計してから導入する。
襲撃依頼の「編成の種別」は初回は通常／強編成を表示し、未実装の精鋭を生成しない。

## 実装時の接続と保存

- 無法港には通常の街と区別できる内部属性を付け、名称比較で判定しない。街の機能は活用しつつ、通常依頼、潮盟、国家戦争の各対象判定で除外する。
- 貴族の拠点自動割当は、黒ひげを通常の街・村へ配置しないようにする。所属・支配表示と面会可能な本拠地を分ける。
- 通常の貴族依頼・国力処理・仕官勧誘のループに黒ひげが混入しないことを確認する。
- 敵の表示集団、戦闘プール、国家勢力、遭遇理由を別の値で扱う。`pirates` 以外なら必ず正規軍という既存判定だけでは賞金稼ぎを区別できない。
- 無法港配置、本拠地、共通好感度、固定された依頼編成・関係悪化対象、売買記録、検問状態を保存する。再読込で港や敵編成が変わらないようにする。
- 禁制品は既存の相場、売却手数料、支持度による購入補正、戦況補正、信仰による売却補正を活用する。無法港に国家戦況を新設しない。
- 既存セーブの世界へ無法港は追加しない。新規ゲームのみ港を生成する。旧セーブでは検問状態の欠損など新領域の初期値だけ補完する。
- READMEと総合設計書 `design/design.md` への操作説明・実装仕様の反映は、実装完了時に行う。

## 検証項目

- 全無法港の到達可能性、配置分散、既存拠点・予約地点との非重複、保存後の配置不変。
- 本拠地のみでの黒ひげとの面会、全港での好感度共有、潮盟の利用不可、造船所と神託報告の利用可。
- 仕官後の海賊依頼新規受注不可と、仕官前に受注した依頼の達成可。
- 依頼報告地の変更や占領後も関係変動先が固定され、達成処理を重複実行しても二重加算されない。
- 禁制品が通常商品・報酬・神託へ混入しないこと、没収後の再調達・依頼達成、売買記録の期限境界。
- 賄賂失敗時の資金消費・好感度減少・再試行不可、兵員・資金ゼロ時の解決、保存復元時の二重処理防止。
- 敵種別の解禁境界、人数の上下限、最大20部隊、固定編成と報酬人数の一致。
- お尋ね者戦闘の好感度・支持度不変と、既存戦争中の国力・戦況処理との適用範囲の確認。
- 新兵種の全UI・GIF表示、編成・雇用・解雇・保存復元と比較シミュレーション。

## 実装値と運用

| 項目 | 初期実装 |
| --- | --- |
| 関係 | −30以下：敵対、−29～−1：警戒、0～29：中立、30以上：厚遇 |
| 依頼の関係変動 | 海賊依頼達成で黒ひげ＋3、固定した通常拠点の支持度−3・担当貴族好感度−3。通常の海賊討伐・賞金首討伐達成は黒ひげ−3 |
| 正規軍の通常遭遇 | 交戦中の敵拠点近傍のみ。お尋ね者条件による追加抽選は停止 |
| 賞金稼ぎ | 海賊側遭遇のうち、強編成基礎人数20以上で15%。海賊兵6種を使用 |
| 検問 | 既存の検問発生時、禁制品所持または30日未満の売買記録があれば50%で摘発。対象は8マス以内の最寄り通常拠点 |
| 賄賂失敗 | 資金消費、担当貴族好感度−3、同じ検問の再試行不可 |
| 禁制品 | 無法港の需要1～3、通常拠点8～10。季節補充は各12個。通常の相場・手数料・信仰補正を使用 |
| 雇用 | 海賊6兵種から5種類、各3人。通常雇用枠に海賊兵は混ぜない |
| 依頼 | 季節ごとに5種類から重複なしで3件。襲撃護衛は国家側の兵種プールを使用 |
| 黒ひげ | 初期好感度0。本拠地のみ謁見可。肖像は当面、海賊勢力の紋章を使用 |

正規軍との通常戦闘だけでは支持度・貴族好感度を変更しない。既存の戦況処理と、所属勢力が敵と交戦中の場合の正規軍撃破による国力変動は維持する。
関係変動の詳細は依頼結果とログに表示し、関係段階が変わった場合だけ追加通知する。
兵種の数値は上記設計表のまま実装。比較シミュレーションは本体の能力値を読み、地形・レベル・部隊数・左右を変えて実行する。結果は絶対的な強弱判定ではなく調整材料とする。
