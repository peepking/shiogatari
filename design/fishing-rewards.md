# 釣り図鑑の追加報酬

釣り竿の報酬と併用する。解放は釣果登録時に自動で行い、一度解放した段階は魚種追加などで達成率が下がっても維持する。既存セーブは読み込み時に達成済み報酬を解放する。

| 達成率 | 報酬 |
| --- | --- |
| 25% | 釣り仲間の伝手。通常の街・村に海兵または海弓兵の独立した雇用枠。Lv1・通常料金・季節5人。兵種は拠点IDで固定し、再入場では補充しない。無法港は対象外。潮盟枠とは併存。 |
| 50% | 漁師の伝手。街の造船所に漁船を別枠販売。5500資金、物資60・兵員10、維持費は定価の2%。解放時に在庫1、季節ごとに最低1隻へ補充。売却在庫は保持。通常の4種は変更しない。イベントの船抽選には含めない。 |
| 75% | 鮮度を保つ知恵。魚の売却単価を1.2倍して切り捨て、その後数量を掛ける。保有済みの魚も対象。通常物資の相場・信仰補正とは独立。 |
| 100% | 海を知る者。達成した次の季節初日から信仰5。季節番号で重複付与を防ぎ、過去の季節分は遡及しない。トーストとログで通知。 |

漁船は1隻につき餌節約率5%、5隻で25%を上限とする。有効なキャストで餌を消費する直前に1回抽選する。餌を1個以上持っている必要があり、釣果の成功・失敗では再抽選しない。船売却で所持数が減れば効果も減る。

解放履歴、雇用在庫と更新季節、完成報酬の最終処理季節を釣りデータに保存する。図鑑で解放状況を確認でき、雇用と造船所では専用枠を明示する。倍率・人数・季節報酬は定数で管理する。

100%報酬の解放後は、ヘッダの信仰から開く「信仰の恩恵」にも「海を知る者」を表示する。図鑑完成が獲得理由であること、毎季節初日に信仰5、達成翌季節から適用、信仰値に依存しない永続効果であることを説明する。
