# UIのアイコン

承認された代表見本を基準にした、中世北欧・西洋の旅の道具や紋章。旧アイコンの形をなぞらず、実寸で分かる輪郭と大きな色のまとまり、素材の陰影で統一する。木・鉄・羊毛・真鍮を共通の素材とし、既存の兵種GIFは変更しない。マップ図柄の追加修正は `image/map/README.md` に記録する。

## 共通の色と粒度

- 濃い紺の輪郭、クリームの羊毛、真鍮の金、木の茶、赤い外套、苔の緑、青灰の鉄を使う。
- 約48〜56pxの論理粒度を目安に作画。静的SVGには基本128pxの透過PNGを埋め込み、20px前後で主題が分かる輪郭を使う。マップと共用する賞金首は176×207pxの切り出し画素を保持する。拡大時は補間しない。
- 信仰は明るいミントグリーン（`#7dffb2`系）の海の波。炎を使わない。部隊員は3人組。香辛料は赤い唐辛子。食料は小麦の穂だけとし、資金は直径を揃えた金貨を使う。
- 所属を表す青・緑・金・赤は区別を残す。数量・名称・状態・読み上げの表示はアイコンに置き換えない。

## 対応範囲

- 資源・物資18種: 船、部隊、信仰、物資、資金、名声、食料、木材、石材、鉄、繊維、塩、香辛料、武具、織物、酒、革、海図。
- 禁制品4種: 違法薬物は薬草と粉末の小包、密造酒は陶器の酒壺、盗品工芸品は宝石の金杯、盗品武具は布を巻いた斧。通常品と専用図柄を分ける。
- 行動20種と所属盾1種: 釣り、依頼、待機、防衛、封鎖、降伏、退出、賞金首、裏の行動、謁見、窓口、釣り小屋、魚図鑑、最終航海、探索、大会戦、海域イベント、救助、造船所、交易。用途ごとに割り当て、釣りと魚図鑑や難破船の3選択も区別する。
- 四季4種: `season-spring.svg`、`season-summer.svg`、`season-autumn.svg`、`season-winter.svg`。日付ヘッダの文字記号を置き換える。
- 勢力4種・貴族6種: `image/factions/`、`image/nobles/`。北海連合・群島同盟・湾岸城塞群は青・緑・金の盾型紋章、外洋海賊は従来の海賊旗。勢力一覧、所属表示、謁見、賞金首の所属に適用する。
- 船11種: `src/fleet/shipArt.js`。帆装・櫂・船楼・盾・漁具を区別し、船団・造船所・図鑑で共用する。
- 信仰施設5段階: `src/faith/tideScene.js`。ミント色の波の紋章を共通に、集いから木造の祠、祭壇、寺院、石造神殿へ描き分ける。
- 魚図鑑4種: `src/fishing/fishingCodexArt.js`。ユーザー指定で一般魚・大物・超大物の旧SVGシルエットと、分類を明かさない点線の円・疑問符へ復元。未使用になった生成PNGと切り出し記録は削除した。

賞金首の行動アイコンは、街のボタン・通常海域と危険海域の現地確認でマップと同じ手配書を共用する。切り出し記録は `atlases/map-bounty.json`。

素材のファイル名と公開描画関数を維持し、資源・取引・依頼・結果の共通表示に反映する。初回素材の参照は `v=20261010-maritime-ui`、追加修正の賞金首は `v=20261011-map-shared-ui`、勢力3種は `v=20261011-heraldry`、小麦と金貨の追加修正は `v=20261011-wheat-coins` として古い表示を更新する。使われていない旧 `lore.js` のデータURI原画は記録として保持する。

全77種類の小さい表示・拡大表示と実際の行動ボタンは `tests/uiArtPreview.html` で確認できる。

## 制作記録と再切り出し

画像生成スキルの組み込みツールで制作。元アトラスは `image/ui/atlases/` に保存し、生成時のプロンプト・元画像のパスは以下に記録する。

- [資源・物資](resources-art.md)
- [行動](actions-art.md)
- [勢力・人物・四季](heraldry-art.md)
- [勢力3種の盾型紋章](faction-crests-art.md)
- [船・潮の施設](dynamic-art.md)
- [承認された代表見本](studies/README.md)

各アトラスのJSONは切り出し範囲を記録する。Sharpを利用できるNode環境で `node scripts/extractUIAtlas.cjs image/ui/atlases/resources.json` のように実行する。生成画像は描き換えず、透過・切り出し・最近傍での表示サイズ調整だけを行う。ゲームの実行時にSharpやビルドは不要。
